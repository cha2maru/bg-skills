# RUL-009：人間の発言・交渉の概念と、ディプロマシー・人狼・花火の再現について

## Exchanges

| # | 話者 | 内容 |
|---|---|---|
| 1 | 利用者 | 他に再現をして新たな概念の使い方を検討できそうなものはある？ |
| 2 | Claude | ハナビ（自分の札だけ見えない・一部だけの知識）、カルカソンヌ（置くと盤が広がる）、トリックテイキング、デッキ構築などを挙げ、ハナビを推奨した |
| 3 | 利用者 | あとは人間の発言、交渉などもボードゲームの概念としてある |
| 4 | Claude | 発言（自由・内緒話・決まった形・禁止・嘘）と交渉（守られる約束・守られなくてよい約束・投票）の幅を整理し、新しい原型は足さずに、発言を操作、提案をアクションに寄せる案を示した |
| 5 | 利用者 | ディプロマシー、人狼、花火を再現してみて |

## Results

| 発言 | 行き先 | 結果 |
|---|---|---|
| #1・#2 | 背景 | WSH-015 の背景 |
| #3 | 要望 | WSH-015（採用）。発言と交渉は、局面の物を変えない人の行為として、記録と見え方の対象にする |
| #5 | 要望（WSH-015）・調査 | 人狼（`examples/werewolf.yaml`。公開）、花火（`local/hanabi.yaml`）、ディプロマシー（`local/diplomacy.yaml`、生成 `local/gen_dip.py`）を再現した。判断と、概念の検討は notes/social/gates.md。反映：CTR-F-001 r1（形式の追加だけ。版は据え置き）・SPC-059〜061 r1 |
