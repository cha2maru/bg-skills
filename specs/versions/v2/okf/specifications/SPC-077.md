# SPC-077：スキルは、プラグインを入れてから最初の 1 局まで（bg-start）と、改訂の 1 周（bg-iterate）を、手順として案内する

## Description

skills/bg-start：プラグインと uv の確かめ、bg init、アイデアの聞き取り、bg-design への受け渡し、最初の bg check・selfplay・serve。skills/bg-iterate：bg status で決めることを選ぶ → 案を variants/ に書く → bg compare --record → 結果を読んで取り込むか決める → 取り込むなら本体を直して版を上げ、journal.md に理由と根拠の試行を書き、古い対局は bg rebase。claude plugin validate がスキルを認める。

## Acceptance Criteria

- **AC-077-1**
  - **Given** プラグインのフォルダ
  - **When** claude plugin validate を行う
  - **Then** bg-start・bg-iterate を含むスキルが認められる
