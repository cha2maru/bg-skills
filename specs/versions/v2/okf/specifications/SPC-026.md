# SPC-026：ライブラリは、部品を定義の初期の置き場と状態に戻す操作を受け付ける

## Description

ループの巻き戻し・準備のやり直しのため。進行状態と裁定は戻さない。既知と付き先は消す。ルールの自動実行ではなく、定義の初期の置き場（start・start_state）だけで決まる。

## Acceptance Criteria

- **AC-026-1**
  - **Given** カードを何枚か手札・火に動かした局面
  - **When** キーパーが「初期に戻す」を操作する
  - **Then** すべてのカードが山札に、初期の状態で戻り、付き先と既知が空になる
- **AC-026-2**
  - **Given** 進行状態が「P2 の手番」の局面
  - **When** キーパーが「初期に戻す」を操作する
  - **Then** 進行状態は「P2 の手番」のまま
