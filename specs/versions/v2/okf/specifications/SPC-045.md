# SPC-045：ライブラリは、手番を終える・勝者を決めて終了する、をアクションの手順で書ける

## Description

引数に players: true を書くと、プレイヤーから選ぶ。手順の progress は値に引数を使える。end は winner を書けば、そのプレイヤーを勝ち、ほかを負けとする（RUL-002 #22）。

## Acceptance Criteria

- **AC-045-1**
  - **Given** 手番が P1 の局面
  - **When** P1 が「手番を終える」を next=P2 で行う
  - **Then** 手番は P2、段階は draw
- **AC-045-2**
  - **Given** 対局中の局面
  - **When** キーパーが「終了する」を winner=P1 で行う
  - **Then** 結果は P1 が勝ち、P2 が負け、理由は R8
