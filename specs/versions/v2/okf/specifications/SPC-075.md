# SPC-075：コマンドは、ゲームの設計の状態（版・ルール・決まっていないこと・機械の層・最近の試行）を一覧で出す

## Description

bg status <定義> [--with 案…] [--experiments experiments.jsonl] は、版、ルールの数（手引き・詳細）、機械の層の無いルール、未決の裁定（問い）、game.open_questions、bg check の誤りの数、複雑さの主な数、最近の試行（3 件）を出す。決めることが無ければ、その欄は空。

## Acceptance Criteria

- **AC-075-1**
  - **Given** 作業場の雛形（open_questions 1・未決の裁定 1）と試行の記録 1 行
  - **When** bg status を行う
  - **Then** 版・未決の裁定の問い・open_questions・文だけのルール・最近の試行 1 件が出て、check の誤りは 0
