# SPC-047：ライブラリは、ダイスを振る・ランダムに 1 つ取る・エリアの部品をマスへ 1 つずつ配る操作を受け付ける

## Description

roll：部品の状態の項目を、取りうる値からランダムに選ぶ（ダイス）。obj に random:<エリア> を書くと、そのエリアの区別された部品からランダムに 1 つ選ぶ（相手の手札から 1 枚取る）。spread：from のエリアの部品（種類で絞れる）を、into のエリアの子（種類で絞れる）へ、1 つずつ順に配る（盤の準備）。乱数は対局の種と操作の通し番号から決まり、記録の再生で同じ結果になる（RUL-003 #1）。

## Acceptance Criteria

- **AC-047-1**
  - **Given** 状態 face（1〜6）を持つダイス
  - **When** キーパーがダイスを振る
  - **Then** 状態 face が 1〜6 のどれかになり、記録を再生すると同じ値になる
- **AC-047-2**
  - **Given** P2 の手札に 3 枚ある局面
  - **When** P1 が「random:hand-P2 を P1 の手札へ動かす」を操作する
  - **Then** P2 の手札は 2 枚、P1 の手札は 1 枚増え、記録には実際に動いた部品の ID が残る
- **AC-047-3**
  - **Given** 箱に地形タイルが 19 枚、盤にマスが 19 ある局面
  - **When** キーパーが「箱の地形タイルを盤のマスへ配る」を操作する
  - **Then** 19 のマスにタイルが 1 枚ずつある
