# SPC-079：ライブラリは、今行える手の一覧と、その席の見え方だけを思考ルーチンに渡し、1 局を最後まで進める

## Description

src/bgskills/bot.py：legal_moves（進行の上で行え、条件を満たす引数の組。候補はその席に見える物だけ）、Ctx（view・moves・part・area・count・find・rnd）、play_game（手番の人・解決待ちに応じる人・手番のない段階のキーパーと各席。断られた手は除いて選び直す）、league（方針を席に回す。種ごとの対の比較）、bg league（--record・--trace）。

## Acceptance Criteria

- **AC-079-1**
  - **Given** ルーン決闘で、相手の手札にカードがある局面
  - **When** 手番の人の合法手と ctx を作る
  - **Then** 合法手の引数に相手の手札の ID が無く、ctx.part で相手の手札を引くと KeyError。自分の手札は引ける
- **AC-079-2**
  - **Given** 収穫の道と、欲張りの思考ルーチン（examples/bots/harvest-greedy.py）
  - **When** 1 局を回す
  - **Then** 終わりの条件で終わり、断られた手が 0、順位が出る
