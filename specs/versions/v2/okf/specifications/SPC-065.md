# SPC-065：ライブラリは、提案（受けたらまとめて行う操作）と、受ける・断る・取り下げ・条件を変えて返すを扱う

## Description

RUL-012 #6（本筋。notes/social/gates.md D6 の次の候補）への対応。守られる約束（カタンのプレイヤー間の交換など）を、発言 say の派生で表す。say に offer（move・attach・set・flip・rotate の操作のリスト）を書くと提案になり、状態は受付中。提案は 2 人の約束で、動く物の元と先は提案者と相手（with）の持ち物の置き場だけ（持ち主のない置き場＝銀行や、3 人目の物は入れられない）。部品の ID でないもの（種類の ID）は出すときに断る。出した人の持ち物が今足りなければ、出した人にだけ警告する。操作 answer（talk：発言の番号、accept：真偽）で答える。相手（with。持ち物が動く相手がいなければ to、それもなければ出した人以外の全員）かキーパーが受けると、中身をすべて行うか、1 つも行わない（足りなければ受け付けない。理由は相手の持ち物を明かさない文だけにする）。提案に action（省くと flow.offer_action）を書くと、成立したときに出した人がそのアクションを行ったことにし、手番・区分・条件から外れていれば警告する（カタンの「手番の人とだけ交換」）。発言には番号 n（取り消しても使い回さない通し番号。対局の session.yaml の talk_next で覚える）を付け、answer・reply_to はこの番号で指す。見せない内緒話（段階の whisper: hidden）は別の番号 hN にして、ほかの人の通し番号に欠けを作らない。見え方の offers_for_me に、自分が答える受付中の提案の番号を出す。断ると閉じ、出した人が accept: false で答えると取り下げ。say に reply_to を書くと、元の提案を閉じて条件を変えて返す。答えも発言として残る。内緒話の提案は、聞いていない人には中身も見せない。画面の発言の欄に提案の状態と、受ける・断る・取り下げるのボタンを出す。画面で提案を出すときは「提案を組み立てる」に切り替え、卓で動かした操作を（行わずに）中身に足して「提案として話す」で出す。コマンドは bg say --offer・--reply-to と bg answer。

## Acceptance Criteria

- **AC-065-1**
  - **Given** P1 が P2 に「木 2 と鉱石 1」を提案している
  - **When** P2 が条件を変えて返し（木 3）、P1 が受ける
  - **Then** 元の提案は閉じ（countered）、木 3 と鉱石 1 が同時に入れ替わる。相手でない P3 は答えられない
- **AC-065-2**
  - **Given** 出した人が持っていない物を渡す提案
  - **When** 相手が受ける
  - **Then** 受け付けず、何も動かない。出した人は取り下げられる
- **AC-065-3**
  - **Given** 画面で、提案の相手を操作する人に選んでいる
  - **When** 発言の欄の「受ける」を押す
  - **Then** 提案が成立し、中身が動く
- **AC-065-4**
  - **Given** 画面の発言の欄で「提案を組み立てる」を押した
  - **When** 山札のカードを捨て札へドラッグし、文を書いて「提案として話す」を押す
  - **Then** カードは動かず、捨て札へ動かす提案が受付中で出る
- **AC-065-5**
  - **Given** 3 人の対局で、P1 が P2 の鉱石をもらう提案を出した（to なし）
  - **When** P3 が受ける／P1 が銀行の物を入れた提案を出す
  - **Then** どちらも受け付けない。P2 の見え方の offers_for_me にだけ提案の番号が出る
