# SPC-064：画面は、5〜8 人の席を卓の辺に並べ、横の欄をたたみ、卓を拡大縮小できる

## Description

RUL-011 #2 への対応。定義の table に席の指定がなければ、5〜8 人は時計回りに左・上・右の辺へ複数の席を並べる（手前は見る立場の 1 人）。上下の辺に席が複数あれば、その辺は卓の横幅いっぱいに広げ、席を横に並べる。見出しの「調べる欄」「ルール欄」で横の欄をたたむと、卓が広がる。「卓の大きさ」で 60〜150% に拡大縮小する（つながりの線は拡大縮小に合わせる）。これらは表示だけで、見る人のブラウザに覚える。

## Acceptance Criteria

- **AC-064-1**
  - **Given** 8 人の人狼の対局
  - **When** 画面を開く
  - **Then** 席は手前 1・左 2・上 3・右 2 に並び、上の 3 席は横に並ぶ
- **AC-064-2**
  - **Given** 同じ画面
  - **When** 「調べる欄」「ルール欄」を押し、卓の大きさを 60% にして、画面を読み直す
  - **Then** 横の欄がたたまれて卓が広がり、読み直してもたたんだまま
