# SPC-061：画面は、絵のない地図（rect と aspect）、プレイヤーの色、いつも出す状態、最初にたたむエリアを描く

## Description

ディプロマシーの再現（RUL-009 #5）で必要になった表示方法。子のエリアがすべて rect を持ち、親に絵がないときは、親の aspect（縦横比）の枠に地図のように並べ、中のつながりの線は描かない（位置から読める）。プレイヤーの color で、持ち主のある部品の縁（丸い駒は地）を塗る。種類の show_state の項目と、書き込む状態の値は、表示の設定に関わらず部品に出す。エリアの folded は、最初にたたんで出す（表示だけ）。

## Acceptance Criteria

- **AC-061-1**
  - **Given** ディプロマシーの 1901 年春、命令を開いた対局
  - **When** 画面で卓を描く
  - **Then** 75 の州が地図の位置に並び、駒は国の色の丸で、開いた命令書に命令の文が出る。駒の置き場はたたまれている
- **AC-061-2**
  - **Given** 人狼の 1 日目の昼
  - **When** 画面で卓を描く
  - **Then** 生死の札に「死んだ…」が出て、開いた投票用紙に投票先が出る
