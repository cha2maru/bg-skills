# SPC-080：コマンドは、思考ルーチンを席に回して多数局を戦わせ、方針ごとの勝ちの割合・平均の順位・席ごとの勝ちと、対の比較の符号検定を出す

## Description

src/bgskills/bot.py：legal_moves（進行の上で行え、条件を満たす引数の組。候補はその席に見える物だけ）、Ctx（view・moves・part・area・count・find・rnd）、play_game（手番の人・解決待ちに応じる人・手番のない段階のキーパーと各席。断られた手は除いて選び直す）、league（方針を席に回す。種ごとの対の比較）、bg league（--record・--trace）。

## Acceptance Criteria

- **AC-080-1**
  - **Given** 収穫の道で、欲張りとでたらめ
  - **When** bg league を 4 種で行う
  - **Then** 8 局（席を回した数）が回り、方針ごとの結果と、paired（どちらが多く勝ったか・符号検定の p）が出る。欲張りの勝ちの割合はでたらめ以上
