# SPC-081：スキルは、配られるファイル（利用者向けのコマンドの手引き docs/commands.md など）だけを指し、今の方針どおりに書かれ、似たスキルとの使い分けを描述文に持つ

## Description

docs/commands.md（利用者向けのコマンドの手引き。CLAUDE.md のコマンドの節から開発者向けの例・local/ を除いたもの）を足し、スキルはそれを指す。local/・sangeki・notes/loop の回の番号・RUL-001 #31 の旧い方針を消す。bg-ai に、見えない部品を引けないのは約束で強制ではないと書く。bg-iterate・bg-balance・bg-ai の描述文に使い分けと英語の呼び方。plugin.json は 0.3.0。

## Acceptance Criteria

- **AC-081-1**
  - **Given** 配ったスキルの SKILL.md
  - **When** CLAUDE.md・local/・sangeki・notes/loop を探す
  - **Then** どれにも当たらない（作品を local/ に置く注意は除く）
- **AC-081-2**
  - **Given** bg-design の SKILL.md
  - **When** 機械の層の方針の文を読む
  - **Then** RUL-016 の方針（作品が選んで書いた分だけ。条件・手順・終わりも書ける）になっている
