# SPC-083：コマンドは、selfplay・compare・league の結果に、席ごと（league は方針ごと）の勝ちの割合の 95% の幅を出し、bg-balance はその流れで比べる

## Description

win_rate と並べて win_ci（[下, 上]。Wilson の 95% の幅）を出す。試行の記録にも入る。bg-balance は案（variants/）・bg compare --record・bg league を使う手順に書き直す。

## Acceptance Criteria

- **AC-083-1**
  - **Given** 収穫の道で bg selfplay を 10 局
  - **When** 結果を見る
  - **Then** 席ごとに win_rate と win_ci があり、下 ≤ win_rate ≤ 上、0 ≤ 下、上 ≤ 1
- **AC-083-2**
  - **Given** bg league を 2 方針で
  - **When** 結果を見る
  - **Then** 方針ごとに win_ci がある
