# SPC-078：ライブラリは、用語の使わない言葉が人の読む文に出たら知らせ、手引きでは用語の初出を決めた表記にする

## Description

terms の各件に avoid（使わない言葉の並び）と first（初出の表記）を書ける。bg check は、ゲームの名前・概要、種類・置き場の名前と説明、部品の title、アクションの名前・when・text、ルール、用語の説明、裁定、段階・フェイズの名前、終わりと知らせの文に avoid の言葉があれば、wording に場所・言葉・言い換えの候補（用語の word）・前後の文を出す（誤りではなく、終わりの値は 0）。登録した用語（word・first）の中の文字と、用語自身の説明で、その用語が避ける言葉は数えない。bg rulebook は、文書の上から用語の word が初めて出た所を first にし、用語の節は first で見出す。

## Acceptance Criteria

- **AC-078-1**
  - **Given** 収穫の道（用語：カード avoid 札、山札、巡 first 巡（ラウンド））に、ルールの文「残りの札は箱へ」と、種類の説明「切札ではない作物の札」（切札は用語）を足した
  - **When** bg check を行う
  - **Then** ルール R1 と種類の説明の 2 か所が wording に出て、言い換えの候補はカード。山札・切札の中の札は出ない。終わりの値は 0
- **AC-078-2**
  - **Given** 収穫の道
  - **When** bg rulebook を行う
  - **Then** 概要の最初の「巡」が「巡（ラウンド）」になり、後の「巡」はそのまま。用語の節は「巡（ラウンド）」で見出す。部品は種類の名前（作物のカード × 27）で出る
