# SPC-071：コマンドは、ゲームの作業場（定義の雛形・案の置き場・試行の記録・設計の日誌）を作り、雛形のまま確かめて回せるようにする

## Description

bg init <フォルダ> [--name 名前] [--players 最小-最大] は、CTR-F-007 の作業場を作る：game.yaml（2 人・山札と手札・引く／出す・山札が尽きたら終わり、の動く雛形。決まっていない点の書き方の例として open_questions と未決の裁定を 1 つずつ含む）、variants/（案の例 1 つ）、experiments.jsonl（空）、journal.md、.gitignore（sessions/）。フォルダが空でなければ作らない。

## Acceptance Criteria

- **AC-071-1**
  - **Given** 空のフォルダ
  - **When** bg init を行う
  - **Then** game.yaml・variants/・experiments.jsonl・journal.md・.gitignore ができ、game.yaml は bg check の誤りが 0、bg selfplay が終わりまで進む
- **AC-071-2**
  - **Given** ファイルのあるフォルダ
  - **When** bg init を行う
  - **Then** 何も書かずに誤りで終わる
