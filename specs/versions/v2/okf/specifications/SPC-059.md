# SPC-059：ライブラリは、発言（全員・聞かせる相手を絞った内緒話）を記録し、見え方に出し、進行ごとの話せる・話せないを警告する

## Description

RUL-009 への対応。操作 say（by・to・text）は局面の物を変えず、話したことを局面の talk に残す（原型：操作の派生）。to を省くと全員に、to を書くとその相手にだけ聞かせる。見え方では、聞いていない人には「話したこと」と相手だけを示し、中身は「（内緒話）」にする。進行の段階かフェーズの talk（true・false・式。式は speaker・to で書く）と talk_text で、話せない時間を宣言する。外れた発言は警告（厳格モードでは拒否）。アクションの手順の say（花火のヒント）は、アクションとして行うので警告しない。`bg say` と画面の「発言」の欄から話せる。

## Acceptance Criteria

- **AC-059-1**
  - **Given** 人狼の夜
  - **When** 人狼が仲間の人狼にだけ話し、村人が全員に話そうとする
  - **Then** 人狼の発言は受け付けられ、村人の発言には警告が出る。ほかの村人の見え方では、人狼の発言は話した人と「（内緒話）」だけになる
- **AC-059-2**
  - **Given** 花火の手番、ディプロマシーの命令の段階
  - **When** プレイヤーが話す
  - **Then** 警告が出る（ヒントのアクションの発言には出ない）
- **AC-059-3**
  - **Given** 画面で、見る立場 P3、P1 から P2 への内緒話がある
  - **When** 「発言」の欄を開き、操作する人を P2 にして話す
  - **Then** P3 には「（内緒話）」と出て、P2 の発言が記録に残る
