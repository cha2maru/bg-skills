# SPC-020：スキルは、対局の後、対局中の裁定ごとに、ゲーム定義の裁定に移す案かルール文を直す案を示し、了承を得てから定義に書く

## Description

ゲームの裁定はゲームごとに定義と一緒に置く（判断の記録 G12）。直した結果はルール本文にも反映する。

## Acceptance Criteria

- **AC-020-1**
  - **Given** 裁定を 1 件含む対局の記録
  - **When** 利用者がエージェントに対局の振り返りを頼む
  - **Then** 最初の問いかけで、その裁定について定義の裁定に移す案とルール文を直す案が示される
- **AC-020-2**
  - **Given** AC-020-1 の問いかけ
  - **When** 利用者が「裁定に移す」と答える
  - **Then** ゲーム定義の裁定にその裁定が足され、定義の版が上がっている
- **AC-020-3**
  - **Given** AC-020-1 の問いかけ
  - **When** 利用者が答える前
  - **Then** ゲーム定義は変わっていない
