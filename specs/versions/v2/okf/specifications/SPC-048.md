# SPC-048：ライブラリと画面は、順番を持つエリアの中で部品を並べ替えられる

## Description

エリアに ordered: true を書くと、並び順に意味があるエリアになる（例：並び順に意味のある手札）。move の at（位置の番号）で、同じエリアの中の位置を変えられる。画面では、順番を持つエリアの中のカードの上に落とすと、そのカードの位置に入れる（重ねるのは Alt を押して落とす）。（RUL-003 #2）

## Acceptance Criteria

- **AC-048-1**
  - **Given** 順番を持つ手札に A・B・C の順で 3 枚
  - **When** 持ち主が C を位置 0 へ動かす
  - **Then** 手札は C・A・B の順
- **AC-048-2**
  - **Given** 順番を持つ手札に A・B・C の順で 3 枚の画面
  - **When** ゲーム設計者が C を A の上へドラッグする
  - **Then** 手札は C・A・B の順で描かれる
