# SPC-073：コマンドは、元の定義と案を同じ条件で多数局回し、終わり方と長さを並べて比べる

## Description

bg compare <定義> --variant 名前=案.yaml …（何個でも。--with で全部に共通の案）--players N --games G は、元（base）と各案を同じ種・同じ局数で selfplay し、案ごとに終わり方の数と割合、平均の手番数、決着なし（打ち切り・決着なし・進められない）の割合を出す。

## Acceptance Criteria

- **AC-073-1**
  - **Given** 作業場の雛形と、手札を変える案
  - **When** bg compare を行う
  - **Then** base と案の 2 行が出て、それぞれに終わり方・平均の手番数・決着なしの割合がある
