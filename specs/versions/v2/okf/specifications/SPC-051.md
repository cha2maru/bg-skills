# SPC-051：ライブラリは、定義の進行の構造（段階・手番・フェーズ・アクションの区分と回数）に沿って進行を記録し、外れた行為に警告を返す

## Description

定義の flow は次を持つ（RUL-003 #6）。

- stages：段階の並び（準備・初期配置・本番など）。段階は order（手番の順：seats＝席順、reverse＝逆順、snake＝往復）、rounds（巡の数。省くと終わりなし）、turn（手番の型）、actions（手番のない段階で行うアクション）を持つ。
- turns：手番の型。phases（フェーズの並び。各フェーズは main＝メインアクション、max＝そのフェーズで行えるメインアクションの数、required＝飛ばせない）、free（フリーアクション：手番のあいだ、フェーズに関係なく行える。max＝手番あたりの回数）、reactions（手番外のプレイヤーが行える対応）を持つ。

進行は局面の flow（段階・巡・手番の番号・手番のプレイヤー・フェーズ・回数）に記録する。操作 advance で次のフェーズへ、最後のフェーズからは次の手番（順に従う）へ、段階の手番が尽きたら次の段階へ進む（to: turn・to: stage で飛ばせる）。進行の状態に active があれば、手番のプレイヤーを写す。

アクションを、今のフェーズのメイン・フリー・手番外の対応に照らし、手番でない・フェーズが違う・回数を超えた・必須のフェーズを飛ばした、のときは警告を返す（拒否しない。合法の判定はしない方針 RUL-001 #31）。今行えるアクションを、区分ごとに示す。

## Acceptance Criteria

- **AC-051-1**
  - **Given** 本番の手番が「ダイス（メイン：振る、1 回）→ 交易と建設」のフェーズを持つ定義で、P1 の手番のダイスのフェーズ
  - **When** エージェントが P1 の今行えるアクションを求める
  - **Then** メインに「ダイスを振る」、フリーに「発展カードを使う」が示される
- **AC-051-2**
  - **Given** AC-051-1 の局面
  - **When** P1 が「ダイスを振る」を 2 回行う
  - **Then** 2 回目に回数を超えた警告が返り、操作は記録される
- **AC-051-3**
  - **Given** 交易と建設のフェーズ（最後のフェーズ）で P1 の手番、席順が P1・P2・P3
  - **When** キーパーが進行を進める（advance）
  - **Then** 手番は P2、フェーズはダイス、手番の番号が 1 増える
- **AC-051-4**
  - **Given** 初期配置の段階（往復、3 人）
  - **When** キーパーが手番を 6 回進める
  - **Then** 手番のプレイヤーは P1・P2・P3・P3・P2・P1 の順に回り、その後は本番の段階の P1 の手番になる
- **AC-051-5**
  - **Given** P2 の手番のダイスのフェーズ
  - **When** P1 が「街道を建てる」を行う
  - **Then** 手番でない・フェーズが違うという警告が返る
