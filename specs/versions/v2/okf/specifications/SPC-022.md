# SPC-022：スクリプトは、指定した複数の対局の記録から、席ごとの勝敗・使われなかった部品とルール・対局ごとの操作数を集計する

## Description

使われなかったルールは、どの操作の理由にも現れなかったルール。集計の項目は上の 3 つから始める（推奨で決めた。RUL-018）

## Acceptance Criteria

- **AC-022-1**
  - **Given** P1 が 2 勝 1 敗、P2 が 1 勝 2 敗の対局の記録 3 件
  - **When** エージェントがスクリプトで 3 件を集計する
  - **Then** P1 の 2 勝 1 敗と P2 の 1 勝 2 敗が示される
- **AC-022-2**
  - **Given** ルール R6 がどの操作の理由にも現れない対局の記録
  - **When** エージェントがスクリプトで集計する
  - **Then** 使われなかったルールとして R6 が示される
