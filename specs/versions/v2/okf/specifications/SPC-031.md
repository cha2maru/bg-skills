# SPC-031：画面は、カードの縦向き・横向きを形で示し、タップと表裏をキー操作で変えられる

## Description

縦向きは縦長、横向き（sideways・tapped など）は横長で描く。タップは種類が定義する「向き以外の最初の状態」を次の値に回す（T キー・ダブルクリック）。表裏は F キー（RUL-002 #8・#11）。

## Acceptance Criteria

- **AC-031-1**
  - **Given** 縦向きのカード
  - **When** ゲーム設計者がカードをダブルクリックする
  - **Then** 記録に状態 turn を sideways にする操作があり、カードが横長で描かれる
- **AC-031-2**
  - **Given** 表向きのカードを選んだ画面
  - **When** ゲーム設計者が F キーを押す
  - **Then** 記録に表裏を返す操作があり、カードが裏面で描かれる
