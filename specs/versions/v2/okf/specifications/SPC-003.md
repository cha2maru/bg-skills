# SPC-003：ライブラリは、ゲーム定義の中の参照先が存在するかを確かめ、存在しない参照を一覧で返す

## Description

確かめる参照：ルールの参照（refs）、部品の初期の置き場、エリアの持ち主、リンクの両端、組のメンバー、属性のうちエリアなどを指すもの。確かめるのは参照先が存在することだけで、ルールの中身の正しさは確かめない（RUL-001 #31）。

## Acceptance Criteria

- **AC-003-1**
  - **Given** すべての参照先が存在するゲーム定義
  - **When** エージェントがライブラリに参照の確認を求める
  - **Then** 存在しない参照は 0 件と示される
- **AC-003-2**
  - **Given** ルール R4 の参照に、定義にない ID「line2」があるゲーム定義
  - **When** エージェントがライブラリに参照の確認を求める
  - **Then** R4 の参照「line2」が存在しない参照として示される
