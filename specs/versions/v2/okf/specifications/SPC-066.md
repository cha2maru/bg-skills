# SPC-066：ライブラリは、名前つきの式（引数を持つ式）を定義の functions に書き、どの式からも関数として呼べるようにする

## Description

notes/arch/gates.md の次の候補「名前つきの式を条件・アクションから呼ぶ」への対応（RUL-012 #9 の後のループ）。定義の functions に `名前: {params: [...], expr: 式}` を書くと、アクションの条件・手順・指標・知らせ・終了の条件など、どの式からも `名前(引数)` で呼べる。名前つきの式どうしも呼び合える。引数の数が違う・呼び出しが深すぎる（50 段）ときは式の誤りにする。bg check は functions の式も確かめる。局面を仮に進めて読むこと（指した後にチェックが残るか）はしない（R3 のような禁じ手は自然文と知らせで扱う）。

## Acceptance Criteria

- **AC-066-1**
  - **Given** チェスの定義に reach・attacks・attacked・in_check を書いた
  - **When** フールズメイトまで指す
  - **Then** 指標 check が白で真になり、知らせに「white のキングがチェックされている」が出る。ナイトの行き先の候補は reach の結果どおり
- **AC-066-2**
  - **Given** 名前つきの式
  - **When** 引数の数を違えて呼ぶ、または自分を呼び続ける
  - **Then** 式の誤り（引数は N 個／呼び出しが深すぎる）になる
