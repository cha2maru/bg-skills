# SPC-082：試験は、スキルの中の bg のコマンド例が、今の bg のサブコマンドと引数に合うかを確かめる

## Description

tests/test_skills.py：skills/*/SKILL.md と docs/commands.md の中の `bg <サブコマンド> …` を抜き出し、argparse の定義にサブコマンドと --引数があるかを確かめる。

## Acceptance Criteria

- **AC-082-1**
  - **Given** スキルに `bg compare … --record …` の例
  - **When** 試験を行う
  - **Then** compare に --record があるので通る
- **AC-082-2**
  - **Given** スキルに無い引数（例：`bg league --nosuch`）を書いた
  - **When** 試験を行う
  - **Then** その行とファイルを示して落ちる
