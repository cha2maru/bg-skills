# SPC-068：ライブラリは、宣言した行為を解決待ちの列（スタック・キュー）に積み、ほかのプレイヤーが応じて積むか見送ったあとに順に解決する

## Description

RUL-013 #2 への対応。アクションに stack: true を書くと、行ったときに手順を行わず、解決待ちの列（局面の stack。番号 n・アクション・行う人・引数）に積む（行った回数は積んだときに数える）。ほかのプレイヤーは、stack のアクションを行って上に積む（割り込み）か、操作 pass で見送る。積んだ人以外の全員が見送ると、次の行為を解決する：既定は後から積んだもの（スタック）、flow.stack: fifo なら先に積んだもの（キュー）。解決は手順を 1 つずつ行い（後の式は結果を読む）、行えなければ何も変えずに外す（立ち消え）。操作 cancel（target：番号）は解決待ちを解決せずに外す（打ち消し。引数に stack: true と書くと候補は解決待ちの番号）。操作 resolve はキーパーが見送りを待たずに解決する。アクションの cost に書いた手順は、積むときにすぐ行う（ルーンを払う、カードを唱えている場所へ。行えなければ積まない）。解決待ちがある間は進行を進めない（警告。厳格なら拒否）。スタックに解決待ちがある間、積まないアクション（during_stack: true でない）は警告（厳格モードなら拒否）。式 stack() で解決待ちを読む。見え方に stack（公開）・stack_waiting（まだ見送っていない人）・stack_done（最近の解決・打ち消し・立ち消え）。bg pass・bg resolve。画面にスタックの帯と、見送る（キーパーは解決する）ボタン。取り消し（undo）は、積んだこと・見送ったこと（とその解決）を戻す。

## Acceptance Criteria

- **AC-068-1**
  - **Given** P1 が雷（P2 に 3 ダメージ）を積んだ
  - **When** P2 が打ち消しで雷を対象に積み、P1 が見送る
  - **Then** 打ち消しが先に解決して雷は打ち消され、P2 のダメージは 0
- **AC-068-2**
  - **Given** 3 人で、P1 が雷を、P2 が回復を積んだ
  - **When** P1 と P3 が見送る
  - **Then** 後から積んだ回復が先に解決し（ダメージがないので立ち消え）、雷はまだ残る。P2 と P3 が見送ると雷が解決する
- **AC-068-3**
  - **Given** スタックに解決待ちがある
  - **When** 積まないアクションを行う
  - **Then** 警告が出る。解決を undo すると、行為は積まれたままに戻る
- **AC-068-4**
  - **Given** 画面で、雷が積まれている
  - **When** P2 として「見送る」を押す
  - **Then** 雷が解決し、スタックが空になる
