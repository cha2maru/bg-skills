# SPC-085：ライブラリは、思考ルーチンが手ごとの点数を返したとき、判断の記録に 1 番目と 2 番目の差を残し、思考ルーチンに、その席に見える記録を渡す

## Description

choose(ctx) は手か (手, 理由) のほか、(手, 理由, 差) を返せる。--trace の 1 行に margin（差）が入る。ctx.log はその席の見え方で伏せた記録（bg log --as と同じ）。

## Acceptance Criteria

- **AC-085-1**
  - **Given** 思考ルーチンが (手, 理由, 0.5) を返す
  - **When** --trace でリーグ戦
  - **Then** その手の行に margin: 0.5
- **AC-085-2**
  - **Given** 相手が手札を見ずに捨てた・内緒の行為をした局面
  - **When** ctx.log を読む
  - **Then** bg log --as と同じく、伏せた中身が出ない
