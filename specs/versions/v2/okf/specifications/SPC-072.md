# SPC-072：ライブラリは、定義に案（同じ形式の断片）を順に重ね、対局・確かめ・回すときに使えるようにする

## Description

定義の読み込みは、案の並び（--with、何枚でも）を順に重ね、最後にシナリオを重ねる。辞書は中まで重ね、並びの要素は id が同じなら差し替え、無ければ足す。トップの remove に挙げた id の要素は除く。bg check・new・fuzz・selfplay・complexity・status・rulebook が --with を受ける。bg new は案を対局のフォルダに写し、session.yaml の variants に名前を残し、再生はその写しを使う。

## Acceptance Criteria

- **AC-072-1**
  - **Given** 手札 3 枚の定義と、手札を 5 枚にする案（準備のアクションを同じ id で差し替え）
  - **When** --with で重ねて bg new し、準備を行う
  - **Then** 手札は 5 枚。対局のフォルダに案の写しがあり、session.yaml の variants に案の名前がある
- **AC-072-2**
  - **Given** ルール R9 を足し、R2 の文を替え、アクション x を remove する案
  - **When** 重ねて読み込む
  - **Then** R9 があり、R2 は案の文、x は無い。ほかの要素は元のまま
- **AC-072-3**
  - **Given** 案を重ねた対局を作った後に、元の案のファイルを書き換えた
  - **When** その対局の局面を出す
  - **Then** 対局のフォルダの写しで再生され、局面は変わらない
