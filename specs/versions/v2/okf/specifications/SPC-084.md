# SPC-084：コマンドは、bg bot-step で、指定した席（人・Claude）の番が来るか対局が終わるまで、ほかの席を思考ルーチンで進める

## Description

bg bot-step <対局> --human P1 --bot P2=bots/x.py [--bot P3=random] [--max N]：対局の記録（log.jsonl）にほかの席の手を足し、止まった理由（human・ended・stuck・max）と、止まったときの手番の人を出す。キーパーのアクション（準備）も進める。進めた手は画面にもそのまま出る（記録が同じ）。

## Acceptance Criteria

- **AC-084-1**
  - **Given** 収穫の道の対局（P1 が人、P2 が欲張り）で P2 の番
  - **When** bot-step を行う
  - **Then** P2 の手が記録に足され、P1 の番で human で止まる
- **AC-084-2**
  - **Given** 人の席の番
  - **When** bot-step を行う
  - **Then** 何も足さず human で止まる
- **AC-084-3**
  - **Given** 終わった対局
  - **When** bot-step を行う
  - **Then** ended で止まる
