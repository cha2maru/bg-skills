# SPC-016：ライブラリは、物の置き場の決まりに反する操作を受け付けず、局面を変えない

## Description

物の置き場の決まり：1 つの部品は同時に 1 か所にだけある。ゲーム定義にない部品・エリアは操作の対象にならない。区別しない部品は、置き場にある個数を超えて動かせない。

## Acceptance Criteria

- **AC-016-1**
  - **Given** 風 N4 が捨て札にある局面
  - **When** キーパーが「N4 を P2 の手札から P1 の火へ動かす」を操作する
  - **Then** 操作は受け付けられず、N4 が P2 の手札にないことが示され、局面は変わらない
- **AC-016-2**
  - **Given** C04 の上に不安カウンターが 1 個ある局面
  - **When** キーパーが「C04 の上の不安カウンター 2 個を補充へ戻す」を操作する
  - **Then** 操作は受け付けられず、個数が足りないことが示され、局面は変わらない
