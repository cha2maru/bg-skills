# SPC-060：ライブラリは、持ち主以外に見えるエリア、一部だけの知識、書き込む状態、非公開の行為を扱う

## Description

RUL-009 への対応。新しい原型は足さず、エリア・オブジェクト・操作の派生で表す。

- 公開範囲の値 others：持ち主以外に見える（花火の手札）
- 操作 know の fields：その項目（属性か状態）だけを知る（花火のヒント、人狼の占いで陣営だけ）。見え方では、表の見えない部品に known を添える。切り混ぜると消える
- 書き込む状態：種類の状態の項目を、値の並びの代わりに型（text・player・area・number）で書く。set は型だけを確かめる（命令書の文、投票用紙の投票先）。伏せて出し、一斉に開くのは、表裏の状態と公開範囲（封をした選択）
- アクションの secret: true：行った本人とキーパーのほかには、記録に出さない（中身・相手のほか、あったことと件数も。人狼の夜の行動。ループ 21 で件数も伏せた）
- 見える部品の見え方に、属性（attributes。title・name を除く）を出す

## Acceptance Criteria

- **AC-060-1**
  - **Given** 花火の 3 人の対局
  - **When** P1 の見え方を出す
  - **Then** 自分の手札は枚数だけ、ほかの人の手札は色と数が見える
- **AC-060-2**
  - **Given** 花火で、P1 が P2 に色のヒントを出した
  - **When** P2 の見え方を出す
  - **Then** 当てはまる札にだけ known: {color} が付き、札のほかの値は見えない
- **AC-060-3**
  - **Given** 人狼の昼、全員が投票用紙に書いて伏せた
  - **When** 村人の見え方を出し、その後、投票を一斉に開く
  - **Then** 開く前は自分の票だけが見え、開いた後は得票の指標が出る。player の型の項目にいない席は書けない
- **AC-060-4**
  - **Given** 人狼の夜の襲撃・護衛・占い
  - **When** 村人の見え方で記録を出す
  - **Then** それらの行為はほかの人の記録に出ず、占い師には相手の陣営だけが見える
