# SPC-074：コマンドは、回した結果を試行の記録に追記し、記録を新しい順に一覧で出す

## Description

bg selfplay と bg compare は --record <experiments.jsonl> で、CTR-F-007 の 1 行（time・game・version・def_hash・variants・players・games・seed・max_turns・tool・result・note）を追記する（--note で書き添え）。bg experiments <experiments.jsonl> [--last N] は新しい順に、日時・版・案・局数・主な結果を出す。

## Acceptance Criteria

- **AC-074-1**
  - **Given** 空の記録
  - **When** bg selfplay --record と bg compare --record を行う
  - **Then** 記録に 1 行ずつ（compare は案ごとに 1 行）足され、def_hash は案を重ねた中身の指紋
- **AC-074-2**
  - **Given** 記録が 3 行
  - **When** bg experiments --last 2 を行う
  - **Then** 新しい 2 行が新しい順に出る
