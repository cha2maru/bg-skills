# SPC-050：ライブラリは、定義の指標（局面から数えて出す値）を計算し、見え方を守って示す

## Description

指標は id・name・text・per（player ならプレイヤーごと）・count（数える部品の条件：kind・in（エリア。子のエリアを含む）・owner・attr・state）か sum（ほかの指標や count に weight を掛けて足す）・visible（all か owner）・refs（関係するルール）を持つ。局面には保存せず、見え方を求めるたびに数える。数える部品に、見る人から表面が見えない部品が含まれるときは、visible が all でも持ち主にだけ示す（RUL-003 #5）。つながりをたどる値（最長の街道など）は指標にせず、用語の自然文に残す。

## Acceptance Criteria

- **AC-050-1**
  - **Given** P1 が使った発展カードの置き場に騎士が 2 枚ある局面
  - **When** エージェントが P2 の見え方を求める
  - **Then** 指標「使った騎士の数」は P1 が 2
- **AC-050-2**
  - **Given** 島に P1 の開拓地が 2 つと都市が 1 つある局面
  - **When** エージェントが見え方を求める
  - **Then** 指標「都市の数」は P1 が 1、「公開の勝利点」は P1 が 4
- **AC-050-3**
  - **Given** P1 の手札に勝利点のカードが 1 枚ある局面
  - **When** エージェントが P1 の見え方と P2 の見え方を求める
  - **Then** P1 の見え方では「勝利点（合計）」が 5、P2 の見え方には P1 の「勝利点（合計）」が示されない
- **AC-050-4**
  - **Given** 指標の count の in に、定義にないエリアを書いた定義
  - **When** エージェントが参照の確認を求める
  - **Then** そのエリアが存在しない参照として示される
