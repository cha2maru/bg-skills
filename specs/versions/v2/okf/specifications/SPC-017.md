# SPC-017：ライブラリは、切る・引くなどの乱数を対局の乱数の種から作り、操作の記録から同じ局面を作り直す

## Description

乱数はキーパー（ライブラリ）だけが扱う。再現は操作の記録の再生で行う（判断の記録 G22）。

## Acceptance Criteria

- **AC-017-1**
  - **Given** 乱数の種 20261118 の対局で、山札を切った後の局面
  - **When** エージェントがライブラリで、同じゲーム定義・同じ種から操作の記録を最初から再生する
  - **Then** 再生後の山札の順番が、記録したときの局面と一致する
- **AC-017-2**
  - **Given** 操作を 30 回記録した対局
  - **When** エージェントがライブラリで操作の記録を再生する
  - **Then** 再生後の局面が、記録の最後の局面と一致する
