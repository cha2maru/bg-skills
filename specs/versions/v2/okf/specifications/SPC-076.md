# SPC-076：コマンドは、定義から人が読む手引き（ルールブック）を書き出す

## Description

bg rulebook <定義> [--with 案…] [--players N] は、Markdown で、題・概要・人数・部品（種類ごとの名前と数）・ルール（手引きのルールを種類の順：準備・手番・アクション・常に・終わり）・用語・決まった裁定（よくある質問）を出す。詳細ルール（detail: true）と未決の裁定は出さない。

## Acceptance Criteria

- **AC-076-1**
  - **Given** 詳細ルールと未決の裁定を持つ定義
  - **When** bg rulebook を行う
  - **Then** 手引きのルールと部品・用語・決まった裁定が出て、詳細ルールの文と未決の問いは出ない
