# SPC-056：ライブラリは、シナリオ・厳格モード・フェーズの順番と人ごとの回数・通過・記憶・値つきの知らせ・行える人を持つ

## Description

惨劇RoopeR の対局の指摘への対応（notes/impl-4/tl-review.md）。対局を作るときに渡すシナリオ（定義に重ねる非公開の設定。対局のフォルダに写す）。厳格モード（警告を拒否にする）。フェイズの per_player・sequence: from_active・pass。advance の until。progress の expr（記憶）。知らせ（signals）の文の {value}。指標の visible: keeper。アクションの by（行える人）。式の on()（直接置かれた物）、parts_in・count_in は子のエリアを含む。

## Acceptance Criteria

- **AC-056-1**
  - **Given** 配役を書いたシナリオと、配役を書いていない定義
  - **When** シナリオを渡して対局を作る
  - **Then** 対局では配役が使え、定義だけを読み込むと配役がない
- **AC-056-2**
  - **Given** 厳格モードの対局で、脚本家行動のフェイズ
  - **When** 主人公がメインアクションを行う
  - **Then** 受け付けられず、記録は増えない
- **AC-056-3**
  - **Given** 主人公行動のフェイズ（by：A・B・C、per_player 1、from_active）でリーダーが A
  - **When** B が先に札をセットする
  - **Then** 「順番は A」の警告が返る
- **AC-056-4**
  - **Given** 神社に暗躍+1 と暗躍禁止、都市の情報屋に移動↑↓と移動←→
  - **When** 脚本家が解決表のアクションを行う
  - **Then** 神社の暗躍は 0、情報屋は神社（斜め）へ移る
- **AC-056-5**
  - **Given** ループの終わりに巫女に友好がある
  - **When** 脚本家がループを終え、次のループの初めに強制効果を行う
  - **Then** 勝敗が記録され、巫女に不安 2 が置かれる
- **AC-056-6**
  - **Given** 主人公の見え方
  - **When** 主人公が「キャラクターが死亡する」を行う
  - **Then** 「行うのは M」の警告が返る
