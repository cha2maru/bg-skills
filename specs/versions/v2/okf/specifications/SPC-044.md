# SPC-044：ライブラリは、エリアに部品が入ったとき、そのエリアの入ったときの状態にする

## Description

エリアは on_enter（例：{facing: up}）を持てる。move・gather で入ったとき、操作が向きを指定していなければ on_enter の状態にする（RUL-002 #21）。

## Acceptance Criteria

- **AC-044-1**
  - **Given** 捨て札が on_enter {facing: up} を持つ定義で、P1 の手札に裏向きのカード
  - **When** P1 がそのカードを捨て札へ動かす（向きを指定しない）
  - **Then** カードは捨て札で表向き
