# WSH-008：TTS 用の開発ツールとしても使いたい

## Background

RUL-001 #39「TTS用開発ツールとしても使えるとよい。」。第一弾で作った TTS への書き出し（bg tts）を受けての発言。

RUL-002 #10「TTSにエクスポートする機能も欲しいな」。

使う場面は、自作ゲームの試作を TTS に取り込んでさわることとする（推定。根拠：#10・#39。判断の記録 J2）。TTS 上の局面を取り込む往復は対象外として後に回す。
