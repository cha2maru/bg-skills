# WSH-007：可視化を、より高度なボードゲームエディタにしたい

## Background

RUL-001 #38「可視化については、より高度なボードゲームエディタにしてもいいかもしれない。」。第一弾で作った画面（bg serve。部品をさわれる卓）を見ての発言。



## Disposition Reason

保留。発言が「かもしれない」で、編集したいもの（ゲーム定義・卓の配置・局面）が決まっていない。第二弾では、画面で見てさわる（WSH-009）と卓の配置（WSH-010）を先に進め、エディタは利用者の確認の後に扱う（判断の記録 J3）。
