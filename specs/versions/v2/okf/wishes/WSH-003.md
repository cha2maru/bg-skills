# WSH-003：存在する、もしくはこれから作るボードゲームのバランス調整をしたい

## Background

RUL-001 #14「最終的には存在、もしくはこれから作るボードゲームを概念化し、操作し、バランス調整やソロプレイモードの開発などをできるようにしたい」のうち、バランス調整（#14-2）。WSH-001 の概念化・操作を前提にしている（発言の順序による。推定）。

ゲーム設計者（とその指示で動くエージェント）が、人のテストプレイの前に、先手の有利や強すぎるカードを見つけるため（推奨で決めた。RUL-018）
