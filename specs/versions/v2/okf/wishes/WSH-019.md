# WSH-019：ゲームの世界観に合う呼び名と表記を決め、ルール・画面・手引きにそろえて出したい

## Background

RUL-029 #1「札よりはカード」「波は波（ウェーブ）」。呼び名は遊びの一部だが、定義の用語は意味を書くだけで、使わない言葉や初出の表記を決められず、文の中の揺れも確かめられなかった。

## Disposition Reason

採用（RUL-029 #2）。
