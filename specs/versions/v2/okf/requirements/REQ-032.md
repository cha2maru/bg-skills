# REQ-032：ゲーム設計者は、用語の使わない言葉と初出の表記を定義に書き、文の揺れを知らされ、手引きに初出の表記で出せる

## Background and Purpose

WSH-019。呼び名をそろえ、独自の言葉には初出で読み・意味を添えたい。

## Non-functional

なし（数値は発言にない）。

## Use Cases

1. 用語に、使う言葉・使わない言葉・初出の表記を書く
2. bg check で、使わない言葉が残っている所を知る
3. bg rulebook で、初出が決めた表記になった手引きを出す

## Out of Scope

- 画面の文言の自動の置き換え（画面は定義の name をそのまま出す）
