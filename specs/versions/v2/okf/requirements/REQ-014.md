# REQ-014：ゲーム設計者は、対局の局面を Tabletop Simulator に取り込める形で書き出せる

## Background and Purpose

TTS 用開発ツールとしても使えるとよい（RUL-001 #39）。TTS にエクスポートする機能も欲しい（RUL-002 #10）。使う場面は、自作ゲームの試作を TTS に取り込んでさわること（判断の記録 J2）。TTS はルールも隠れ情報も守らないので、キーパーの局面（すべて見える）を書き出す。

## Non-functional

なし（数値は発言にない）。既存ゲームの画像は使わない（RUL-001 #37 に準ずる）。

## Use Cases

1. ゲーム設計者がエージェントに TTS への書き出しを頼む
2. エージェントが bg tts で書き出す
3. ゲーム設計者が TTS の Saved Objects に置いて呼び出す

## Out of Scope

- TTS 上の局面を取り込む往復（External Editor API・Lua）
- カードの絵柄の画像の生成
- TTS の Workshop への投稿
