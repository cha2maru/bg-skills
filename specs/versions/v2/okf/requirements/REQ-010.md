# REQ-010：他の開発者は、ゲーム定義と局面を、機械で処理でき人が読めるファイルとして読み書きできる

## Background and Purpose

書き出した定義は、JSON や YAML など、機械処理ができつつ人が読める形にする（RUL-001 #33）。ライブラリはゲームエンジンにもスクリプトにも使う（#23）。形式は YAML を基本とし、キーは英語・中身は日本語とする（判断の記録 G7・G23）。

## Relation to Existing Requirements

ゲーム定義の読み込み・書き出し・参照の整合は、REQ-001 と同じ要件（SPC-001〜SPC-003）で満たす。

## Non-functional

なし（数値は発言にない）。

## Use Cases

1. 他の開発者がライブラリでゲーム定義を読み込む
2. 他の開発者が自分のツールでゲーム定義を処理する
3. 他の開発者がライブラリで書き出す

## Out of Scope

- ライブラリの公開・配布の方法当面は配布しない（このリポジトリを uv で使う）。配布するなら git から uv add できる形（推奨で決めた。RUL-018）
