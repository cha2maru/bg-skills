# 要求

- [REQ-001 エージェントは、ボードゲームをルール・プレイヤー・コンポーネントに沿ったゲーム定義として書き表し、保存できる](/requirements/REQ-001.md)
- [REQ-002 ゲーム設計者は、作っているボードゲームの定義を版ごとに残し、版の違いを確かめられる](/requirements/REQ-002.md)
- [REQ-003 エージェントは、既存のボードゲームの資料から、出典と未決を付けたゲーム定義に再構成できる](/requirements/REQ-003.md)
- [REQ-004 エージェントは、ゲーム定義と局面から、何がどこにどんな状態であるかとその意味を読み取れる](/requirements/REQ-004.md)
- [REQ-005 エージェントは、あるプレイヤーの立場で、そのプレイヤーに見えてよい情報だけを受け取れる](/requirements/REQ-005.md)
- [REQ-006 エージェントは、ゲーム定義に理解のための不足がないかを確かめられる](/requirements/REQ-006.md)
- [REQ-007 エージェントは、キーパーとして対局を始め、ルールを読んで部品を操作しながら対局を進められる](/requirements/REQ-007.md)
- [REQ-008 エージェントは、ルール文で決着しない解釈を裁定し、ゲーム定義の裁定として残せる](/requirements/REQ-008.md)
- [REQ-009 ゲーム設計者は、頼めば、現時点のゲーム定義からルール説明を受け取れる](/requirements/REQ-009.md)
- [REQ-010 他の開発者は、ゲーム定義と局面を、機械で処理でき人が読めるファイルとして読み書きできる](/requirements/REQ-010.md)
- [REQ-011 ゲーム設計者は、テストプレイの記録とゲーム定義から、バランスの偏りの指摘と直す案を受け取れる](/requirements/REQ-011.md)
- [REQ-012 ゲーム設計者は、エージェントと一緒に、ソロプレイ用の自動の対戦相手のルールを設計し、テストプレイで確かめられる](/requirements/REQ-012.md)
- [REQ-013 ゲーム設計者は、定義した結果を画面で見て部品をさわり、さわった結果を記録に残せる](/requirements/REQ-013.md)
- [REQ-014 ゲーム設計者は、対局の局面を Tabletop Simulator に取り込める形で書き出せる](/requirements/REQ-014.md)
- [REQ-015 ゲーム設計者は、卓の配置（中央に置くもの、プレイヤーの席）を定義で決め、その配置で局面を見られる](/requirements/REQ-015.md)
- [REQ-016 エージェントは、六角のマス目（ヘックスマップ）の盤を略記で定義し、その隣接関係をルールと画面で使える](/requirements/REQ-016.md)
- [REQ-017 ゲーム設計者は、ルールに結びついたアクションを定義し、画面やコマンドから 1 回の操作で行える](/requirements/REQ-017.md)
- [REQ-018 ゲーム設計者は、すべての部品が箱に入った状態から対局を始め、セットアップの手順を確かめられる](/requirements/REQ-018.md)
- [REQ-019 エージェントは、ゲームの進行（段階・手番・フェーズ・周回）に沿って、今行えることを知り、進行を進められる](/requirements/REQ-019.md)
- [REQ-020 エージェントは、ルールの構造的な条件と費用を、行う前に確かめられる](/requirements/REQ-020.md)
- [REQ-021 エージェントは、局面から数えて出す値（指標）と、終わりや出来事の知らせを読める](/requirements/REQ-021.md)
- [REQ-022 エージェントは、ルールに書かれた手順（産出など）を、定義に宣言した手順として 1 回で行える](/requirements/REQ-022.md)
- [REQ-023 ゲーム設計者は、ゲームの定義と、対局ごとの非公開の設定（脚本・配役など）を分けて持てる](/requirements/REQ-023.md)
- [REQ-024 ゲーム設計者は、対局ごとに、条件や進行から外れた行為を受け付けない厳格な進め方を選べる](/requirements/REQ-024.md)
- [REQ-025 エージェントは、対局の中で、全員に・一部の相手にだけ話し、その発言が記録と見え方に残る](/requirements/REQ-025.md)
- [REQ-026 ゲーム設計者は、隠れた情報の作品（自分だけ見えない手札、一部だけの知識、伏せて書く命令・投票、非公開の行為）を定義に書ける](/requirements/REQ-026.md)
- [REQ-027 ゲーム設計者は、プラグインを入れた自分のプロジェクトに、新しいゲームの作業場を作り、最初の定義を確かめて回せる](/requirements/REQ-027.md)
- [REQ-028 ゲーム設計者は、定義を写さずに、数値やルールの違う案を重ねて試し、元と案を比べられる](/requirements/REQ-028.md)
- [REQ-029 ゲーム設計者は、試した結果（版・案・条件・結果）を記録に残し、改訂の判断の根拠として見返せる](/requirements/REQ-029.md)
- [REQ-030 ゲーム設計者は、ゲームの設計の状態（決まっていないこと・機械の層の範囲・最近の結果）を一覧で見られる](/requirements/REQ-030.md)
- [REQ-031 ゲーム設計者は、人と試し遊びするための手引き（ルールブック）を定義から作れる](/requirements/REQ-031.md)
