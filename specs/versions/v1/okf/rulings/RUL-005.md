# RUL-005：古典のゲームのサンプルと、プリミティブからの派生について

## Exchanges

| # | 話者 | 内容 |
|---|---|---|
| 1 | 利用者 | 将棋、オセロ、チェス、麻雀などの古典もサンプルに加えて |
| 2 | 利用者 | 定義したものはエリアやオブジェクトなどのプリミティブなものの派生とするようにできる限りして。絶対にならないものだけを追加する |
| 3 | 利用者 | 再開 |

## Results

| 発言 | 行き先 | 結果 |
|---|---|---|
| #1 | 開発ルール | 古典（将棋・オセロ・チェス・麻雀）の定義を examples/ に足す。ルールが公知で作品の権利の問題がないため、公開してよい（RUL-001 #37 は商用の既存作が対象）と解した（推定）。足りない概念を洗い出す材料にもする |
| #2 | 設計への指定 | 概念の設計で、定義に現れるもの（盤・マス・手札・駒・カード・トークン・山・場所の性質など）は、できる限りエリアとオブジェクトの派生（kinds の base）として表す。派生で表せないものだけを新しい概念として足す。対象：PRD-001 r1（概念の契約）。反映：CTR-F-001 r1 |
| #3 | 背景 | 中断していた作業の再開 |
