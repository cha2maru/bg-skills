# REQ-007：エージェントは、キーパーとして対局を始め、ルールを読んで部品を操作しながら対局を進められる

## Background and Purpose

ゲームエンジンは、最悪の場合、エージェントがオブジェクトを操作する形で対応してよい（RUL-001 #26）。ルールを裁定するキーパーを設けてもいい（#8）。

キーパーは対局の側にいる特別なプレイヤーで、局面のすべてを見て、ルールに従って部品を操作し、乱数を使い、裁定する。ゲーム定義には書かない（判断の記録 G5）。プレイヤーの席と、席につく者（人・エージェント・オートマ）を分ける（判断の記録 G8）。操作はライブラリのコマンドを通して行い、局面のファイルを直接書き換えない（判断の記録 G3）。

## Non-functional

なし（数値は発言にない）。

## Use Cases

1. 利用者がエージェントに対局を頼む（ゲーム定義の版・人数・着席者）
2. エージェントがキーパーとして対局を始める
3. キーパーがルールを読み、部品を操作する
4. キーパーが対局の終了と結果を記録する

## Out of Scope

- ルールの合法性の自動判定（キーパーが判断する）
- 対戦用の思考ルーチン（席につくのはエージェント）
