# 要求

- [REQ-001 エージェントは、ボードゲームをルール・プレイヤー・コンポーネントに沿ったゲーム定義として書き表し、保存できる](/requirements/REQ-001.md)
- [REQ-002 ゲーム設計者は、作っているボードゲームの定義を版ごとに残し、版の違いを確かめられる](/requirements/REQ-002.md)
- [REQ-003 エージェントは、既存のボードゲームの資料から、出典と未決を付けたゲーム定義に再構成できる](/requirements/REQ-003.md)
- [REQ-004 エージェントは、ゲーム定義と局面から、何がどこにどんな状態であるかとその意味を読み取れる](/requirements/REQ-004.md)
- [REQ-005 エージェントは、あるプレイヤーの立場で、そのプレイヤーに見えてよい情報だけを受け取れる](/requirements/REQ-005.md)
- [REQ-006 エージェントは、ゲーム定義に理解のための不足がないかを確かめられる](/requirements/REQ-006.md)
- [REQ-007 エージェントは、キーパーとして対局を始め、ルールを読んで部品を操作しながら対局を進められる](/requirements/REQ-007.md)
- [REQ-008 エージェントは、ルール文で決着しない解釈を裁定し、ゲーム定義の裁定として残せる](/requirements/REQ-008.md)
- [REQ-009 ゲーム設計者は、頼めば、現時点のゲーム定義からルール説明を受け取れる](/requirements/REQ-009.md)
- [REQ-010 他の開発者は、ゲーム定義と局面を、機械で処理でき人が読めるファイルとして読み書きできる](/requirements/REQ-010.md)
- [REQ-011 ゲーム設計者は、テストプレイの記録とゲーム定義から、バランスの偏りの指摘と直す案を受け取れる](/requirements/REQ-011.md)
- [REQ-012 ゲーム設計者は、エージェントと一緒に、ソロプレイ用の自動の対戦相手のルールを設計し、テストプレイで確かめられる](/requirements/REQ-012.md)
