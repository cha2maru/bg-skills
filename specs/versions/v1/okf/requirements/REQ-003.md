# REQ-003：エージェントは、既存のボードゲームの資料から、出典と未決を付けたゲーム定義に再構成できる

## Background and Purpose

既存のボードゲームを、概念モデルを使ってエージェントが理解できる形に再構成する（WSH-006。RUL-001 #30-1）。人間は行間を読めるが、エージェントには不足のない情報が要る（#28）。そのため、資料で決着しない点を推測で埋めず、未決として残す。記述ごとに出典を付け、資料の内容と推測を分ける。

再構成した既存ゲームの定義は公開しない。作ったものが対応できるかの確かめに使う（RUL-001 #37）。

## Non-functional

なし（数値は発言にない）。既存ゲームの定義は公開しない（RUL-001 #37。開発ルール）。既存ゲームの定義は git 管理から外したフォルダ（local/）に置く（推奨で決めた。RUL-018）

## Use Cases

1. 利用者がエージェントに既存ゲームの資料を示して再構成を頼む
2. エージェントが資料を読み、ゲーム定義を書く
3. エージェントが決着しない点を未決として報告する

## Out of Scope

- 再構成した定義の公開・配布（RUL-001 #37）
- 画像からの文字の読み取り（OCR）の仕組み元にするのはルールブックなどの文書とカードの一覧（文字）。画像は任意（assets）。既存の実装は参考にだけ使う（推奨で決めた。RUL-018）
