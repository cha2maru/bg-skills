# WSH-004：存在する、もしくはこれから作るボードゲームのソロプレイモードを開発したい

## Background

RUL-001 #14「最終的には存在、もしくはこれから作るボードゲームを概念化し、操作し、バランス調整やソロプレイモードの開発などをできるようにしたい」のうち、ソロプレイモードの開発（#14-3）。発言の「など」から、ほかにも同様の目的がありうる。

【要確認：誰が・なぜソロプレイモードを開発したいか】【要確認：「など」に当たるほかの目的】
