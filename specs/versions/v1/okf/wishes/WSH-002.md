# WSH-002：ボードゲームをいろんな形でエクスポートしたい

## Background

RUL-001 #2「そのうえで、いろんな形でエクスポートできるようにしたい」。#1（WSH-001）のオブジェクト的な管理を前提にしている（発言の「そのうえで」）。

RUL-001 #34：「現時点でのルール説明を作って」と頼めば、ルール説明をアーティファクトとして作れるようにする。

ゲーム設計者が、試作を人と遊ぶ（TTS への書き出し）・ルールを配る（ルール説明）ために使う（推奨で決めた。RUL-018）
