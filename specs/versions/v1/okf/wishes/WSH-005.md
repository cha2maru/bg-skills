# WSH-005：エージェントが定義を見ながら盤面を把握し、何がどんな状態であるかとその意味を不足なく理解できるようにしたい

## Background

RUL-001 #27「ルール、プレイヤーなども概念として定義し、その定義情報をみつつ盤面を把握すれば、何がどんな状態であるかとその意味を理解することが可能な状態にする」のうち、理解できる状態にすること（#27-2）。

関係する発言：#25「目的は定義。」、#26「ゲームエンジンは最悪エージェントがオブジェクトを操作する形で対応してもいい」。ルールの自動実行がない場合、盤面を操作する者は定義から状態の意味を読み取る必要がある（推定。根拠：#26）。

RUL-001 #28「人間は行間を読める。これはエージェントが不足なくボードゲームを理解することができるようにし、いろんなことをできるようにするのが目的。」：理解する主体はエージェント。人間なら行間で補える部分も、定義に書かれている必要がある。
