# WSH-015：プレイヤーの発言・交渉・隠れた情報のやりとりを、ゲームの定義と対局で扱いたい

## Background

RUL-009 #3「人間の発言、交渉などもボードゲームの概念としてある」、#5（ディプロマシー・人狼・花火の再現）。これまで、プレイヤーどうしの会話は記録の外にあり、エージェントどうしの対局で誰が何を言ったかが残らなかった。カタンの交換は、言い出した側だけで行う形だった。

## Disposition Reason

採用（RUL-009 #5 で再現を指示された）。
