## 構造の検討への材料

実装で自然に分かれた単位：

| 単位 | 中身 | 構造の案 |
|---|---|---|
| 定義 | 読み込み・略記の展開・索引（definition.py） | ライブラリのコンポーネント「定義」 |
| 定義の道具 | 書き出し・参照の確認・差分・逆引き（tools.py） | 同上（定義に含めるか分ける） |
| 対局 | 局面・操作・記録と再生（session.py） | ライブラリのコンポーネント「対局」 |
| 見え方 | 見え方・意味つきの局面（view.py） | ライブラリのコンポーネント「見え方」 |
| コマンド | `bg`（cli.py） | スクリプト（システム） |

契約の候補：定義ファイルの形式（`bg-def/0.1`）、対局のファイル（`session.yaml`＋`log.jsonl` の操作の形）、見え方の出力の形、`bg` コマンドの引数と出力。
