## 構造の検討への材料（第二弾で増えた単位）

| 単位 | 中身 | 構造の案 |
|---|---|---|
| 定義 | definition.py（略記・六角・箱・表示方法・上限・卓の配置） | ライブラリ：定義 |
| 定義の道具 | tools.py（書き出し・参照の確認・差分・逆引き） | ライブラリ：定義（または道具） |
| 対局 | session.py（局面・操作・アクション・記録と再生・準備の確かめ） | ライブラリ：対局 |
| 見え方 | view.py | ライブラリ：見え方 |
| コマンド | cli.py（bg） | スクリプト |
| 画面 | server.py・ui.html | 画面（システム。bg serve） |
| TTS | tts.py | 書き出し（コンポーネント） |

契約の候補：定義ファイルの形式（bg-def/0.1：kinds・states の show・areas の layout・on_enter・capacity・table・actions）、対局のファイル（session.yaml・log.jsonl の操作）、見え方の出力、HTTP（/api/def・view・log・op・action）、bg コマンド、TTS の Saved Object への対応。
