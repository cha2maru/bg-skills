# SPC-002：ライブラリは、ゲーム定義を、キーは英語・中身は日本語の YAML の決まった書き方で書き出す

## Description

書き出しの形式は YAML（判断の記録 G7）。長い自然文は複数行のまま書く。値が真偽値や数に読み違えられうる文字列は引用符で囲む。キーは英語、中身は日本語（判断の記録 G23）。

## Acceptance Criteria

- **AC-002-1**
  - **Given** ライブラリが読み込んだゲーム定義
  - **When** 開発者がライブラリで YAML に書き出し、そのファイルを読み込み直す
  - **Then** 読み込み直した定義の要素と値が、書き出す前と一致する
- **AC-002-2**
  - **Given** 複数行のルール本文を持つゲーム定義
  - **When** 開発者がライブラリで YAML に書き出す
  - **Then** ファイルの中でルール本文が改行を保った複数行で書かれている
- **AC-002-3**
  - **Given** 値が「no」の文字列を持つゲーム定義
  - **When** 開発者がライブラリで YAML に書き出し、読み込み直す
  - **Then** その値が真偽値ではなく文字列「no」として読み込まれる
