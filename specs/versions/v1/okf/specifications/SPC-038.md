# SPC-038：ライブラリは、種類の状態の値ごとに表示方法（回転と表裏）を持ち、見え方・画面・TTS の書き出しはそれに従う

## Description

状態の値は、意味の文（text）と表示方法（show）を持てる。show は回転（rotate：0・90・180・270。時計回り）と表裏（face：up・down）。部品の表示方法は、その部品のすべての状態の値の show を重ねたもの（回転は足し合わせ、表裏は後の値が勝つ）。カードは回転 4 通り×表裏 2 通りの 8 通りの向きを表せる（RUL-002 #18）。

裏向き（face: down）の判定は show から行う（第一弾の決め打ち `facing: down` を置き換える。show のない定義には従来の決め打ちを残す）。画面は回転 0・180 を縦長、90・270 を横長で描き、上の向きを矢印で示す。TTS の書き出しは回転を回転 Y、裏向きを回転 Z 180 にする。

## Acceptance Criteria

- **AC-038-1**
  - **Given** 状態 orientation の値が 8 つ（上・右・下・左×表・裏）あり、値「右・裏」の show が回転 90・裏の定義
  - **When** 開発者がライブラリで、状態を「右・裏」にした部品の表示方法を求める
  - **Then** 回転 90・裏が示される
- **AC-038-2**
  - **Given** AC-038-1 の部品が、表面を全員に見せるエリアにある局面
  - **When** キーパーが、既知でないプレイヤーの見え方を求める
  - **Then** 表面は見えないと示される（裏向き）
- **AC-038-3**
  - **Given** AC-038-1 の部品
  - **When** エージェントが bg tts で書き出す
  - **Then** その部品は回転 Y 90・回転 Z 180 で置かれる
- **AC-038-4**
  - **Given** 状態 turn の値 sideways の show が回転 90 の定義
  - **When** ゲーム設計者が画面で、その状態のカードを見る
  - **Then** カードは横長で、上の向きが右を指す矢印とともに描かれる
