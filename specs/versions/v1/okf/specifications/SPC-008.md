# SPC-008：スキルは、資料で決着しない点を推測で埋めず、ゲーム定義の未決に残して報告する

## Description

人間は行間を読めるが、エージェントには不足のない情報が要る（RUL-001 #28）。資料に書かれていない点を、一般的な遊び方などで補わない。

## Acceptance Criteria

- **AC-008-1**
  - **Given** 守りの付いた薪が風以外で取り除かれたときの扱いが書かれていない資料
  - **When** 利用者がエージェントにその資料からの再構成を頼む
  - **Then** ゲーム定義の未決に、その扱いが問いとして書かれている
- **AC-008-2**
  - **Given** AC-008-1 の再構成
  - **When** エージェントが再構成を終える
  - **Then** 利用者への報告に、未決の一覧がある
