# SPC-021：スキルは、利用者が頼むと、最新の版のゲーム定義からルール説明をアーティファクトとして作る

## Description

ルール説明は人が読む文書で、ゲーム定義の ID（R3 など）を名前に置き換えて書く。未決は「決まっていないこと」として示す。

## Acceptance Criteria

- **AC-021-1**
  - **Given** かがり火のゲーム定義（版 2）
  - **When** ゲーム設計者がエージェントに「現時点でのルール説明を作って」と頼む
  - **Then** アーティファクトのルール説明に、ゲーム名・版 2・準備・手番・終了の説明がある
- **AC-021-2**
  - **Given** AC-021-1 のルール説明
  - **When** ゲーム設計者がルール説明を読む
  - **Then** 本文にルールの ID（R1〜R8）が現れず、名前と文で書かれている
- **AC-021-3**
  - **Given** 未決を 1 件持つゲーム定義
  - **When** ゲーム設計者がエージェントにルール説明を頼む
  - **Then** ルール説明に「決まっていないこと」としてその未決が示される
