# SPC-067：ライブラリは、手番が替わるたびに局面を覚え、式の repeats() で今の局面が何回目かを読めるようにする

## Description

notes/arch/gates.md の次の候補「局面の履歴を読む条件」への対応（RUL-012 の後のループ 3）。advance で手番の人が替わったとき、局面の物（置き場・状態・付いた物）と手番の人から作る鍵を数える。式の repeats() は、今の局面が手番の替わり目に現れた回数を返す。チェスの 3 回の繰り返し、将棋の千日手（4 回）を知らせ（signals）で書いた。局面は記録の再生で作るので、数も再生で決まる。連続王手かどうか・ステイルメイト（指せる手がない）は読まない（自然文）。

## Acceptance Criteria

- **AC-067-1**
  - **Given** チェスの初期局面
  - **When** 両者がナイトを出して戻すのを 3 回くり返す
  - **Then** 3 回目に戻ったときだけ「同じ局面が 3 回目」の知らせが出る
