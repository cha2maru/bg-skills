# SPC-018：ライブラリは、対局の終了と席ごとの結果を記録する

## Description

結果は席ごとの勝ち・負け・引き分けと、終了の理由（どのルールによるか）。終了の判断はキーパーが行う。

## Acceptance Criteria

- **AC-018-1**
  - **Given** かがり火の対局で山札が尽きた局面
  - **When** キーパーが「終了。P1 勝ち、P2 負け。理由 R8」を記録する
  - **Then** 対局の記録に終了・席ごとの結果・理由 R8 が残り、以後の操作は受け付けられない
