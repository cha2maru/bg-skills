# SPC-028：画面は、部品のドラッグ・クリックの操作を受け付け、操作者と理由のルールを付けて記録に残す

## Description

エリアに落とすとそのエリアへ、カードに落とすとその上へ、Shift を押してカードに落とすとその下へ差し込む。マウスとタッチの両方で同じに動く。

## Acceptance Criteria

- **AC-028-1**
  - **Given** 山札にカードがある局面、操作する人に P1、理由に R2 を選んだ画面
  - **When** ゲーム設計者がカードを手札へドラッグする
  - **Then** 記録の末尾に、そのカードの移動・操作者 P1・理由 R2 がある
- **AC-028-2**
  - **Given** 記録が 3 件の対局
  - **When** ゲーム設計者が受け付けられない操作（ない部品を動かす）をする
  - **Then** 画面に受け付けられなかった理由が出て、記録は 3 件のまま
