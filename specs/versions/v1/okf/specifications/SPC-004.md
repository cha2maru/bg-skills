# SPC-004：ライブラリは、エリアの入れ子・位置・リンク・組・形状・公開範囲の既定値を、ゲーム定義の要素として保持する

## Description

エリアは中にエリアを持てる（RUL-001 #11）。位置は、基本は上位のエリアの原点からの位置（#16）。リンクは 2 つのエリアの関係で、種別・向き・説明を持つ（#16。判断の記録 G16）。組は名前のついたエリアの集まり（判断の記録 G16）。形状は任意で持ち、中身は解釈しない（#17）。公開範囲は情報の段階（存在・枚数・裏面・表面・順番）ごとの見せる相手（判断の記録 G4）。順番を持つエリア（山札など）を宣言できる（判断の記録 G15）。

## Acceptance Criteria

- **AC-004-1**
  - **Given** 盤の中に 4 つの場所エリアがあり、各場所が盤の原点からの位置を持つゲーム定義
  - **When** エージェントがライブラリで場所エリアの位置を求める
  - **Then** 各場所の、盤の原点からの位置が示される
- **AC-004-2**
  - **Given** 病院と都市の間に種別「縦」のリンクがあるゲーム定義
  - **When** エージェントがライブラリで病院のリンクを求める
  - **Then** 都市への種別「縦」のリンクが、その説明とともに示される
- **AC-004-3**
  - **Given** 形状（線の定義）を持つエリアがあるゲーム定義
  - **When** 開発者がライブラリで読み込み、書き出す
  - **Then** 形状の中身が変わらずに書き出される
