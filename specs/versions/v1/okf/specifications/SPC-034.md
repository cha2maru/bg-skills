# SPC-034：ライブラリは、定義の卓の配置（中央・席ごとのエリア・人数ごとの席）を人数に合わせて解く

## Description

席を省くと、2 人は手前と対面、3 人は手前・左・右、4 人は手前・左・奥・右。席ごとのエリアは {player} で書く。卓の配置に書いたエリアの参照先も確かめる。

## Acceptance Criteria

- **AC-034-1**
  - **Given** 卓の配置（席を省く）を持つ 2 人のゲーム
  - **When** 開発者がライブラリで卓の配置を解く
  - **Then** P1 が手前、P2 が対面で、各席に player-P1・player-P2 が割り当てられる
- **AC-034-2**
  - **Given** 卓の配置に定義にないエリア「deck2」を書いた定義
  - **When** エージェントが参照の確認を求める
  - **Then** 「deck2」が存在しない参照として示される
