# SPC-057：ライブラリと画面は、定義のエリアの背景画像と、部品の表と裏の画像を、見え方を守って描く

## Description

RUL-006 への対応。画像は原型の表示方法の 1 つで、新しい概念ではない。エリアの image は背景、オブジェクト（なければ種類）の image は表、back_image は裏の絵。値は文字列か、`{default: …, "<状態>=<値>": …}`（状態で替わる絵）。assets.root（定義のファイルからの相対パス）の下だけを画面が配り（/assets/…）、assets.credit を画面に表記する。見えない部品は裏の絵だけを示す。エージェント向けの短い局面（--compact）には画像を出さない。

## Acceptance Criteria

- **AC-057-1**
  - **Given** 山札のエリアに image、薪の種類に image、カードの種類に back_image を持つ定義
  - **When** P2 の見え方で、P1 の火（表向きの薪と裏向きの薪）を求める
  - **Then** 表向きの薪には表の絵、裏向きの薪には裏の絵だけが付く
- **AC-057-2**
  - **Given** 死体のとき別の絵を持つキャラクター（posture=dead）
  - **When** キャラクターを死体にする
  - **Then** そのキャラクターの絵が死体の絵に替わる
- **AC-057-3**
  - **Given** 画面のサーバーが動いている
  - **When** assets.root の外のファイル（../ を含む）か、ないファイルを求める
  - **Then** 404 が返る
- **AC-057-4**
  - **Given** 惨劇RoopeR の再現の対局を画面で開く
  - **When** 卓を描く
  - **Then** 病院・神社・都市・学校にボードの絵が背景として描かれ、画像の表記（惨劇コモンズ作成）が画面に出る
