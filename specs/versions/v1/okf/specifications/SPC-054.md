# SPC-054：ライブラリは、進行の構造に周回・フェイズごとの行う人・席の一部の順・手番の数・知らせを持てるようにする

## Description

惨劇RoopeR の再現（RUL-004 #3）で、SPC-051 の進行の構造に足りなかったもの。flow.cycle（from〜to の段階を times 回くり返す。ループ）、段階の order に席の並び（例：主人公 3 人でリーダーが回る）、段階の turns（手番の数＝日数）、フェイズの by（そのフェイズのメインアクションを行う席。省くと手番のプレイヤー）、flow.signals（式が真のときにキーパーに知らせる文。終了以外：今日の事件の条件など。G8 の一部）。式から progress(key)・cycle()・stage()・phase()・turn_in_stage() を読める。

## Acceptance Criteria

- **AC-054-1**
  - **Given** ループの準備 → 7 日 → を 3 回くり返し、その後に最後の戦いがある定義
  - **When** キーパーが 7 日を終える
  - **Then** 段階はループの準備に戻り、周回は 2 になる。3 周目の 7 日の後は最後の戦い
- **AC-054-2**
  - **Given** 脚本家行動のフェイズ（by: M）
  - **When** 主人公 A がメインアクションを行う
  - **Then** 「行うのは M」の警告が返る
- **AC-054-3**
  - **Given** 日の段階（order: A・B・C、turns: 7）
  - **When** キーパーが日を進める
  - **Then** リーダー（手番のプレイヤー）は A → B → C → A と回る
- **AC-054-4**
  - **Given** 今日の事件の犯人が不安臨界以上の局面で、事件のフェイズ
  - **When** キーパーが局面を見る
  - **Then** 「今日の事件の条件を満たしている」が知らされ、主人公の見え方には出ない
