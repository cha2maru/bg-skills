# SPC-062：画面は、多角形のエリア（poly）を形どおりに描き、形の内側だけでドロップを受ける

## Description

RUL-010 #1 への対応。エリアは poly（親のエリアの中の多角形の頂点 [[x, y], …]。割合）と color（塗り）を持てる。子のエリアが rect か poly を持つとき、画面は親の枠（絵の縦横比か aspect）に置く。poly は外接する四角に置いて多角形で切り抜き、輪郭線を重ね、中身は重心に置く。切り抜いた外側はクリック・ドロップを受けない（下のエリアが受ける）。形は表示方法で、隣接はリンクで決まる（形から隣を導かない）。あわせて、列より広い六角の盤は列の幅に縮めて描く。

## Acceptance Criteria

- **AC-062-1**
  - **Given** 正方形を対角線で分けた 2 つの三角形のエリア（外接する四角は同じ）
  - **When** 左下の点と右上の点で、どのエリアに当たるかを調べ、駒を右上へドラッグする
  - **Then** 左下は左下の三角形、右上は右上の三角形に当たり、駒は右上の三角形に入る
- **AC-062-2**
  - **Given** ディプロマシーの対局
  - **When** 画面で卓を描く
  - **Then** 75 の州が多角形の地図として描かれ、海と陸は塗りで分かれる
