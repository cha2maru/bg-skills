# SPC-070：ライブラリは、ゲーム定義の裁定（ルールの穴を埋める。決まった・未決・一般の原則）を確かめ、意味とともに出し、対局中の裁定から持ち帰る候補を出す

## Description

RUL-017 への対応。定義の rulings の各件に、question・decision・reason・rules・refs・principle・status（decided・open）・authority（official＞author＞designer＞keeper）・by・date・sources・found_in・supersedes・engine を書ける。bg check は形（決まった裁定に decision、問いの無い裁定）と参照先（rules・refs・supersedes）を確かめ、未決を open_rulings に出す（誤りではない）。部品の意味（bg show --meaning）に、関わるルールの裁定を添える。bg complexity はルールごとの裁定を machine_layer に含め、裁定の数を出す。bg rulings は定義の裁定の一覧と、対局のフォルダを渡せば対局中の裁定のうち定義にまだ無いもの（未決の問いと同じなら同じ id）を、定義に貼れる形で出す。

## Acceptance Criteria

- **AC-070-1**
  - **Given** ルーン決闘の定義（裁定 3 件：原則 1・決まった 1・未決 1）
  - **When** bg check と bg complexity を行う
  - **Then** 誤りは無く、未決の J3 が出る。ルール R5 の機械の層に「ruling J3（未決）」が出る
- **AC-070-2**
  - **Given** 決まった裁定に decision が無い、または関わるルールが無い
  - **When** bg check を行う
  - **Then** それぞれを指摘する
- **AC-070-3**
  - **Given** 人狼の対局で、キーパーが定義では未決の「棄権できるか」と、定義に無い問いを裁いた
  - **When** bg rulings <対局> を行う
  - **Then** 未決の J3 を決まった裁定に書き換える候補と、新しい裁定の候補が、定義に貼れる形で出る
