# SPC-014：スクリプトは、ゲーム定義の版・人数・席ごとの着席者・乱数の種を指定して対局を作り、部品を初期の置き場に置いた局面を作る

## Description

着席者の種別は、人・エージェント・オートマ（判断の記録 G8）。キーパーは対局の側にいて、ゲーム定義には書かない（判断の記録 G5）。準備のルール（配る・切るなど）は、この後キーパーが操作として行う。

## Acceptance Criteria

- **AC-014-1**
  - **Given** かがり火のゲーム定義（版 1）
  - **When** エージェントがスクリプトで、人数 2、P1 にエージェント a、P2 にエージェント b、乱数の種 20261118 を指定して対局を作る
  - **Then** 対局に版 1・人数 2・着席者・乱数の種が記録され、全部品が初期の置き場（山札）にある局面ができる
- **AC-014-2**
  - **Given** 人数の上限が 4 のゲーム定義
  - **When** エージェントがスクリプトで人数 5 を指定して対局を作る
  - **Then** 対局は作られず、人数が範囲外であることが示される
