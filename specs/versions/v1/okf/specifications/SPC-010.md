# SPC-010：ライブラリは、部品・種類・状態の値・用語を指定すると、それを参照するルールの一覧を返す

## Description

ルールの参照（refs）の逆引き。

## Acceptance Criteria

- **AC-010-1**
  - **Given** ルール R3・R4・R5・R8 が薪の種類を参照するゲーム定義
  - **When** エージェントがライブラリに薪の種類を参照するルールを求める
  - **Then** R3・R4・R5・R8 が示される
- **AC-010-2**
  - **Given** どのルールからも参照されない部品
  - **When** エージェントがライブラリにその部品を参照するルールを求める
  - **Then** 参照するルールがないことが示される
