# SPC-053：ライブラリは、局面の構造を読む式で、アクションの値・繰り返し・分岐、条件、指標、終了の検出を書けるようにする

## Description

式は Python の式の一部（比較・算術・条件式・内包表記）と、決まった関数（state・attr・kind・owner・where・children・linked・parts_in・count_in・metric・players・seat・active・turn・entered・longest_path ほか）だけを使える（G1 選択式・G2 値と式）。アクションの let（値）・each（式で選んだものごとに繰り返す）・if（分岐）（G3）、条件の expr と、アクション全体の require（G4：ほかの引数・プレイヤー・行う人への条件）、指標の expr（G6：最長の路など）、進行の end_when（G7：終了を知らせる。記録はキーパー）で使う。部品がエリアに入った手番を局面に覚える（G5）。spread に配る部品の順・配る先の順・飛ばす条件を書ける（G10）。式はアクションを始めたときの局面で計算する。式は宣言した手順・条件・値を計算するだけで、いつ行うかを自動で決めない（RUL-001 #26・#31 との線引き。concept-review.md）。（RUL-004 #2）

## Acceptance Criteria

- **AC-053-1**
  - **Given** カタンの局面で、ダイスの合計が 6、数字 6 のタイルに接する交点に P1 の開拓地と P2 の都市がある
  - **When** キーパーが「出目で産出する」を行う
  - **Then** P1 にそのタイルの資源が 1 枚、P2 に 2 枚渡る
- **AC-053-2**
  - **Given** 盗賊のタイルに接する建物を持たないプレイヤー P3
  - **When** P1 が「手札から 1 枚取る」の相手の候補を求める
  - **Then** P3 は「盗賊のタイルに接する建物がない」の理由つきで示される
- **AC-053-3**
  - **Given** この手番に買った発展カード
  - **When** 持ち主がそれを使う
  - **Then** 「買った手番には使えない」の警告が返る
- **AC-053-4**
  - **Given** P1 の街道が 3 本つながっている局面
  - **When** エージェントが指標「最長の街道」を求める
  - **Then** P1 は 3
- **AC-053-5**
  - **Given** P1 の勝利点が 10 点の局面
  - **When** キーパーが局面を見る
  - **Then** 「10 点以上のプレイヤーがいる」が知らされる
