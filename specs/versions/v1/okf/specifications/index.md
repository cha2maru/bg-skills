# 要件

## 機能要件

- [SPC-001 ライブラリは、ゲーム定義のファイルを読み込み、各要素を ID で取り出せるオブジェクトとして保持する](/specifications/SPC-001.md)
- [SPC-002 ライブラリは、ゲーム定義を、キーは英語・中身は日本語の YAML の決まった書き方で書き出す](/specifications/SPC-002.md)
- [SPC-003 ライブラリは、ゲーム定義の中の参照先が存在するかを確かめ、存在しない参照を一覧で返す](/specifications/SPC-003.md)
- [SPC-004 ライブラリは、エリアの入れ子・位置・リンク・組・形状・公開範囲の既定値を、ゲーム定義の要素として保持する](/specifications/SPC-004.md)
- [SPC-005 ライブラリは、種類ごとに状態の項目と値ごとの意味の文、属性の項目、使い方を保持する](/specifications/SPC-005.md)
- [SPC-006 ライブラリは、ゲーム定義の 2 つの版の違いを、足した・消した・変えた要素の一覧で示す](/specifications/SPC-006.md)
- [SPC-007 スキルは、既存ゲームの資料から作ったゲーム定義の記述に、根拠の資料と箇所を出典として付ける](/specifications/SPC-007.md)
- [SPC-008 スキルは、資料で決着しない点を推測で埋めず、ゲーム定義の未決に残して報告する](/specifications/SPC-008.md)
- [SPC-009 ライブラリは、局面とゲーム定義から、意味つきの局面を書き出す](/specifications/SPC-009.md)
- [SPC-010 ライブラリは、部品・種類・状態の値・用語を指定すると、それを参照するルールの一覧を返す](/specifications/SPC-010.md)
- [SPC-011 ライブラリは、局面を 1 人のプレイヤーから見た見え方に切り出し、見えない情報をその理由とともに示す](/specifications/SPC-011.md)
- [SPC-012 スキルは、理解テストとして、ゲーム定義だけを渡したエージェントに決まった質問へ答えさせ、答えられなかった点と推測で補った点を報告する](/specifications/SPC-012.md)
- [SPC-013 スキルは、決まったチェックリストの項目ごとに、ゲーム定義に記述があるかを報告する](/specifications/SPC-013.md)
- [SPC-014 スクリプトは、ゲーム定義の版・人数・席ごとの着席者・乱数の種を指定して対局を作り、部品を初期の置き場に置いた局面を作る](/specifications/SPC-014.md)
- [SPC-015 ライブラリは、基本の操作を局面に適用し、操作ごとに操作者と理由のルールを記録する](/specifications/SPC-015.md)
- [SPC-016 ライブラリは、物の置き場の決まりに反する操作を受け付けず、局面を変えない](/specifications/SPC-016.md)
- [SPC-017 ライブラリは、切る・引くなどの乱数を対局の乱数の種から作り、操作の記録から同じ局面を作り直す](/specifications/SPC-017.md)
- [SPC-018 ライブラリは、対局の終了と席ごとの結果を記録する](/specifications/SPC-018.md)
- [SPC-019 ライブラリは、対局中の裁定を、問い・決定・理由・決めた者・日時・関係するルールとともに操作の記録に残す](/specifications/SPC-019.md)
- [SPC-020 スキルは、対局の後、対局中の裁定ごとに、ゲーム定義の裁定に移す案かルール文を直す案を示し、了承を得てから定義に書く](/specifications/SPC-020.md)
- [SPC-021 スキルは、利用者が頼むと、最新の版のゲーム定義からルール説明をアーティファクトとして作る](/specifications/SPC-021.md)
- [SPC-022 スクリプトは、指定した複数の対局の記録から、席ごとの勝敗・使われなかった部品とルール・対局ごとの操作数を集計する](/specifications/SPC-022.md)
- [SPC-023 スキルは、利用者が頼むと、集計とゲーム定義の数値から、バランスの偏りの指摘と直す案を報告する](/specifications/SPC-023.md)
- [SPC-024 ライブラリは、オートマのルールを、特定の席の着席者が従うルールとしてゲーム定義に保持する](/specifications/SPC-024.md)

## 非機能要件

- なし（数値・条件が発言にないため、各要求の Non-functional に記載）
