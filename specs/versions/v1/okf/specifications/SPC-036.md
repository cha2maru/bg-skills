# SPC-036：画面は、六角のマス目を、互い違いに並んだ六角形で描く

## Description

マスの位置（q, r）から画面の位置を計算する。マスの中の部品とリンクの線は、ほかのエリアと同じに描く。

## Acceptance Criteria

- **AC-036-1**
  - **Given** 半径 2 の六角のマス目の盤
  - **When** ゲーム設計者が画面を開く
  - **Then** 19 個のマスが六角形の盤の形に描かれ、駒を別のマスへドラッグできる
