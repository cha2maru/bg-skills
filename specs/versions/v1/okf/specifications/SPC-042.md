# SPC-042：画面は、エリアを表示の上でだけたたみ、局面と記録は変えない

## Description

エリアの見出しの印でたたむ・ひらく。たたんだエリアは見出しと部品の数だけを示す。たたんだ状態は見る人のブラウザにだけ残す（RUL-002 #25）。

## Acceptance Criteria

- **AC-042-1**
  - **Given** 山札に 18 枚ある画面
  - **When** ゲーム設計者が山札の見出しの印を押す
  - **Then** 山札は見出しと「18」だけになり、記録の件数は変わらない
