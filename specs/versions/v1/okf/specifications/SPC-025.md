# SPC-025：ライブラリは、エリアの置ける上限（capacity）を超える操作を受け付けたうえで、警告を返す

## Description

上限はルールの領分なので、操作は拒否しない（RUL-001 #31）。キーパーが誤りに気づけるように警告だけを返す。区別しない部品は個数で数える。

## Acceptance Criteria

- **AC-025-1**
  - **Given** 上限 1 のマスに記号が 1 つある局面
  - **When** キーパーが同じマスに記号をもう 1 つ置く
  - **Then** 操作は記録され、そのマスの上限 1 を超えたという警告が返る
- **AC-025-2**
  - **Given** 上限 1 の空のマス
  - **When** キーパーが記号を 1 つ置く
  - **Then** 警告は返らない
