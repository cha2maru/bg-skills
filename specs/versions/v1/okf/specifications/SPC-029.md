# SPC-029：画面は、エージェントが bg op や HTTP で行った操作を、操作から 2 秒以内に描き直す

## Description

画面と bg op は同じ記録（log.jsonl）を使う。同時に書いても、古い局面に対して受け付けない。

## Acceptance Criteria

- **AC-029-1**
  - **Given** 画面で開いている対局
  - **When** エージェントが bg op でカードを捨て札へ動かす
  - **Then** 2 秒以内に、画面の捨て札にそのカードが描かれる
