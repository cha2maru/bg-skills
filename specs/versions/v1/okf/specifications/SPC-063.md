# SPC-063：ライブラリは、アクションの手順を 1 つずつ行い、続く式がその結果の局面を読む進め方（stepwise）を持つ

## Description

RUL-011 #1 への対応。アクションに stepwise: true を書くと、手順の操作を 1 つ作るたびに行い、後の let・if・each の式はその結果の局面で計算する（コインを投げてから表か読む、ダメージを置いてから HP を読む）。書かなければ、今まで通りアクションを始めたときの局面で計算する。どちらでも、手順のどれかが受け付けられなければ 1 つも記録しない。記録には行った操作が残り、再生は記録の操作をそのまま行うので、再生の結果は変わらない。

## Acceptance Criteria

- **AC-063-1**
  - **Given** 精霊獣デュエルで、相手のバトル場の HP 60 の精霊獣にダメージカウンターが 4 個ある
  - **When** 20 ダメージのワザを使う
  - **Then** 同じアクションの中できぜつし、精霊獣はトラッシュに、カウンターは補給に戻り、サイドが 1 枚手札に入る
- **AC-063-2**
  - **Given** コインでマヒにするワザ
  - **When** ワザを使う
  - **Then** コインがおもてのときだけ相手がマヒになる
