# SPC-046：ライブラリは、六角の盤の略記から、マスの頂点と辺の置き場と、そのつながりを作る

## Description

layout.hex に vertices: true・edges: true を書くと、マスの角（頂点）と辺を子エリアとして作る（隣のマスと共有する頂点・辺は 1 つ）。頂点・辺は位置 xy（マスの大きさを 1 とした平面の座標）を持つ。リンク：マス—頂点（corner）、マス—辺（side）、頂点—辺（end）、頂点—頂点（adjacent。辺でつながる 2 頂点）。（RUL-003 #1。SPC-035 の要確認「辺・頂点」への答え）

## Acceptance Criteria

- **AC-046-1**
  - **Given** 半径 2 の六角の盤（頂点・辺あり）
  - **When** 開発者がライブラリで定義を読み込む
  - **Then** 頂点が 54、辺が 72 できる
- **AC-046-2**
  - **Given** AC-046-1 の盤
  - **When** 開発者が中心のマスのリンクを求める
  - **Then** 頂点 6 つと辺 6 つにつながる
- **AC-046-3**
  - **Given** AC-046-1 の盤
  - **When** 開発者が外周でない頂点のリンクを求める
  - **Then** マス 3 つ、辺 3 つ、頂点 3 つにつながる
