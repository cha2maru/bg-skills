# SPC-015：ライブラリは、基本の操作を局面に適用し、操作ごとに操作者と理由のルールを記録する

## Description

基本の操作：動かす、めくる、状態を変える、差し込む（付き先を持つ）、切る、補充から出す、補充へ戻す、既知を足す。ルールの合法性は判定しない（キーパーが判断する）。操作はコマンドを通して行い、局面のファイルを直接書き換えない（判断の記録 G3）。

## Acceptance Criteria

- **AC-015-1**
  - **Given** 風 N4 が P2 の手札にある局面
  - **When** キーパーが「N4 を捨て札へ動かす。操作者 P2、理由 R4」を操作する
  - **Then** N4 が捨て札の一番上にあり、記録の末尾にその操作・操作者・理由が残っている
- **AC-015-2**
  - **Given** 薪 W6-1 が P1 の火の一番上にある局面
  - **When** キーパーが「風 N6 を W6-1 の下に差し込み、向きを横にする」を操作する
  - **Then** N6 の付き先が W6-1 で、N6 の状態「回転」が横向きになっている
