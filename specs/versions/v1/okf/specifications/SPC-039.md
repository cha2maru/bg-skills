# SPC-039：ライブラリは、定義のアクションを、引数を埋めた基本の操作の並びとして、すべてか何もしないかで行い、記録に残す

## Description

アクションは id・name・rule（結びつくルール）・when（いつ行えるか。自然文）・params（選ぶもの。名前と、選ぶ元のエリア）・steps（基本の操作の型。{actor} と引数の名前で埋める）を持つ。行うと、手順の操作がそれぞれ操作者 actor・理由 rule・アクションの id を付けて記録に残る。途中の操作が受け付けられなければ、どの操作も記録しない。参照の確認は、アクションの rule と、手順のエリアの参照も見る。

## Acceptance Criteria

- **AC-039-1**
  - **Given** アクション「山札から 1 枚引く」（rule R2、手順：top:deck を hand-{actor} へ）を持つ定義の局面
  - **When** P1 がそのアクションを行う
  - **Then** 山札の一番上だったカードが P1 の手札にあり、記録に操作者 P1・理由 R2・アクション draw が残る
- **AC-039-2**
  - **Given** アクション「薪を火に置く」（引数 card：hand-{actor} から、手順：card を fire-{actor} へ表向きで）を持つ定義で、P1 の手札に W5-2 がある局面
  - **When** P1 が card=W5-2 でそのアクションを行う
  - **Then** W5-2 が P1 の火の一番上に表向きである
- **AC-039-3**
  - **Given** 2 つの操作の手順を持ち、2 つ目が受け付けられない局面
  - **When** P1 がそのアクションを行う
  - **Then** アクションは受け付けられず、記録は増えない
- **AC-039-4**
  - **Given** アクションの rule に定義にないルール「R9」を書いた定義
  - **When** エージェントが参照の確認を求める
  - **Then** 「R9」が存在しない参照として示される
