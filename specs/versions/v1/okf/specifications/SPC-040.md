# SPC-040：画面は、見る立場のプレイヤーが行えるアクションをボタンで示し、選ぶものを選ばせてから行う

## Description

行う人は、操作する人（キーパーなら見る立場のプレイヤー）。ボタンには名前と、結びつくルールと「いつ」の文を添える。引数があれば、選ぶ元のエリアにある部品から選ばせる。

## Acceptance Criteria

- **AC-040-1**
  - **Given** アクション「山札から 1 枚引く」を持つ定義の画面で、操作する人が P1
  - **When** ゲーム設計者が「山札から 1 枚引く」のボタンを押す
  - **Then** P1 の手札が 1 枚増えて描かれ、記録にアクション draw が残る
- **AC-040-2**
  - **Given** アクション「薪を火に置く」（引数 card）を持つ定義の画面で、操作する人が P1
  - **When** ゲーム設計者がボタンを押し、P1 の手札から W5-2 を選ぶ
  - **Then** W5-2 が P1 の火に表向きで描かれる
