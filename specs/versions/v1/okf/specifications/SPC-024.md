# SPC-024：ライブラリは、オートマのルールを、特定の席の着席者が従うルールとしてゲーム定義に保持する

## Description

オートマのルールは、区分「オートマ」と、それに従う席を持つ。オートマのルールはゲーム定義の中に、ほかのルールと同じ形で持つ（推奨で決めた。RUL-018）

## Acceptance Criteria

- **AC-024-1**
  - **Given** 席 P2 のオートマのルールを 3 つ持つゲーム定義
  - **When** エージェントがライブラリで P2 のオートマのルールを求める
  - **Then** その 3 つのルールが示される
- **AC-024-2**
  - **Given** AC-024-1 のゲーム定義で、P2 の着席者をオートマにした対局
  - **When** キーパーが P2 の見え方を求める
  - **Then** 見え方に P2 のオートマのルールの本文が含まれる
