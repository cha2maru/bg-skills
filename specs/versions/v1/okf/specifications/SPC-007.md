# SPC-007：スキルは、既存ゲームの資料から作ったゲーム定義の記述に、根拠の資料と箇所を出典として付ける

## Description

出典は、資料・箇所・照合の有無を持つ（判断の記録 G18）。資料の要約で書き、原文を写すかは利用者が決める。【要確認：仮定＝資料はルールブックなどの文書】

## Acceptance Criteria

- **AC-007-1**
  - **Given** ルールブックの文書
  - **When** 利用者がエージェントにルールブックからの再構成を頼む
  - **Then** 作られたゲーム定義のルールそれぞれに、ルールブックの箇所を示す出典が付いている
- **AC-007-2**
  - **Given** 利用者からの情報で、資料に記載のない数値（例：置き場の上限）
  - **When** 利用者がエージェントにその数値を定義に入れるよう頼む
  - **Then** その数値の出典に、利用者からの情報で資料と照合していないことが示されている
