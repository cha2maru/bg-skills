# SPC-052：ライブラリは、アクションの引数が満たすべき構造の条件を宣言として持ち、満たさない値に警告を返し、候補を条件つきで示す

## Description

引数は require（条件の並び）と owner（その人の部品だけ）を持てる。条件は、エリアの中身とリンクのつながりだけで決まる述語：empty、has（種類・持ち主・属性）、linked（リンクの種類と、つながる先が満たす条件。入れ子にできる）、not・any・all。text は満たさないときの文。アクションを行うとき、条件を満たさない値には警告を返す（拒否しない）。引数の候補を、条件を満たすかとその理由つきで示す（bg candidates・HTTP /api/candidates）。エリアのリンク先と中身を引ける（bg near）。カタンの再現でエージェントが補助スクリプトを書いた点（リンクの読み取り、距離の決まり・つながりの検査）への対応（RUL-003 #7、エージェントの対局の報告）。

## Acceptance Criteria

- **AC-052-1**
  - **Given** 隣の交点（リンクの種類 adjacent）に開拓地がある交点
  - **When** P1 がその交点に開拓地を置くアクションを行う
  - **Then** 「距離の決まり」の警告が返り、操作は記録される
- **AC-052-2**
  - **Given** P1 の開拓地がある交点と、その交点に端（end）でつながる辺
  - **When** エージェントが P1 の「初期配置で街道を置く」の辺の候補を求める
  - **Then** その辺は条件を満たす候補として、つながらない辺は「自分の開拓地につながっていない」の理由つきで示される
- **AC-052-3**
  - **Given** 中心のタイル
  - **When** エージェントがそのタイルのリンク先（種類 corner）を求める
  - **Then** 6 つの交点と、それぞれの中身が示される
- **AC-052-4**
  - **Given** P2 の街道 1 本を引数にした「街道を建てる」
  - **When** P1 がそのアクションを行う
  - **Then** 「P1 の部品ではない」の警告が返る
