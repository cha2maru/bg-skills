# SPC-019：ライブラリは、対局中の裁定を、問い・決定・理由・決めた者・日時・関係するルールとともに操作の記録に残す

## Description

裁定は、ルール文で決着しない場面でキーパーが下す決定。

## Acceptance Criteria

- **AC-019-1**
  - **Given** 対局中の局面
  - **When** キーパーが「問い：守り付きの薪が取り除かれたら守りはどうなるか。決定：一緒に捨て札へ置く。理由：…。関係するルール R4」を裁定として記録する
  - **Then** 対局の記録に、その裁定が問い・決定・理由・決めた者・日時・関係するルールとともに残っている
