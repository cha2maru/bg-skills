# SPC-012：スキルは、理解テストとして、ゲーム定義だけを渡したエージェントに決まった質問へ答えさせ、答えられなかった点と推測で補った点を報告する

## Description

質問の例：いま誰の手番で何ができるか、この部品のこの状態は何を意味するか、あなたに見えていない情報は何か、勝つ条件まであと何が要るか、この操作の後に何が起きるか。答えに推測（「おそらく」「一般的には」）が出た箇所を、行間（RUL-001 #28）の候補として挙げる。

## Acceptance Criteria

- **AC-012-1**
  - **Given** 守りの付いた薪が風以外で取り除かれたときの扱いが書かれていないゲーム定義
  - **When** 利用者がエージェントに理解テストを頼む
  - **Then** 報告に、その扱いが答えられなかった点または推測で補った点として挙がっている
- **AC-012-2**
  - **Given** 理解テストの報告
  - **When** 利用者が報告を読む
  - **Then** 報告の各点に、関係するゲーム定義の要素の ID が示されている
