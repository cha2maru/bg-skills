# SPC-041：画面は、部品・エリアをクリックすると、それに結びつくアクションを示し、そこから行える

## Description

部品に結びつくアクションは、その部品を引数の候補に含むもの。エリアに結びつくアクションは、手順・引数がそのエリアを使うもの（例：山札をクリックすると「山札から 1 枚引く」）。結びついた引数は選んだ部品・エリアで埋め、残りの引数だけを選ばせる（RUL-002 #24）。

## Acceptance Criteria

- **AC-041-1**
  - **Given** 操作する人が P1 で、P1 の手札に薪 W5-2 がある画面
  - **When** ゲーム設計者が W5-2 をクリックし、調べる欄の「薪を火に置く」を押す
  - **Then** W5-2 が P1 の火に表向きで描かれ、記録にアクション stoke が残る
- **AC-041-2**
  - **Given** 操作する人が P1 の画面
  - **When** ゲーム設計者が山札のエリアをクリックする
  - **Then** 調べる欄に「山札から 1 枚引く」が示される
