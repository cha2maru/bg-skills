# SPC-009：ライブラリは、局面とゲーム定義から、意味つきの局面を書き出す

## Description

意味つきの局面は、エリアごとに、エリアの意味の文、置かれた部品（順番・付き先を含む）、各部品の状態とその値の意味の文、関係するルールの ID を並べる。進行状態（手番・フェイズなど）と、いま関係するルールの本文を含める（判断の記録 G9）。推論はせず、局面と定義の機械的な結合だけを行う。

## Acceptance Criteria

- **AC-009-1**
  - **Given** かがり火の局面で、P1 の火に薪 6 があり、その下に風が横向きで差し込まれている
  - **When** エージェントがライブラリに意味つきの局面を求める
  - **Then** P1 の火の項に、風が薪 6 に付いた守りであることと、その意味の文、ルール R5 の ID が示される
- **AC-009-2**
  - **Given** 進行状態が「P1 の手番、行為を選ぶ段階」の局面
  - **When** エージェントがライブラリに意味つきの局面を求める
  - **Then** 手番が P1 であることと、その段階に関係するルール R2 の本文が示される
