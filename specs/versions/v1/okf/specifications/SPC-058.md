# SPC-058：ライブラリと画面は、進行に入ったときの手順で目印を動かし、絵の上の位置にマスを重ね、丸いトークンを描く

## Description

RUL-007 への対応。flow の段階と手番に on_start（手順の並び。アクションの steps と同じ書き方）を持てる。advance で段階か手番に入ったとき、その手順を行う。手順の操作は記録に足さず、記録を再生すると同じ局面になる。エリアは rect（親のエリアの中の [x, y, 幅, 高さ] の割合）を持てる。親が image を持ち、子がすべて rect を持つとき、画面は絵の縦横比で子を絵の上に重ねる。種類の shape: round の部品は丸く描く。

## Acceptance Criteria

- **AC-058-1**
  - **Given** 手番の on_start に「目印を t{手番の番号} へ動かす」がある定義
  - **When** 手番を 2 回進める
  - **Then** 目印は t3 にあり、記録は advance の 2 件だけで、記録を読み直しても同じ局面になる
- **AC-058-2**
  - **Given** 惨劇RoopeR の再現の対局（3 ループの脚本）
  - **When** 1 日目から 2 日目へ進め、その後ループを終える
  - **Then** 日の目印は 2 日目、ループの目印は「2 ループで始める」のマスにあり、事件の日の目印は主人公にも見える
- **AC-058-3**
  - **Given** データボードの絵と、マスごとの rect
  - **When** 画面で卓を描く
  - **Then** マスが絵の丸の上に重なり、目印は丸いトークンとして描かれる
