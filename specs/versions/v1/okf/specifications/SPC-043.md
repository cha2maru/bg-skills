# SPC-043：ライブラリは、どの定義にも卓の外のエリア「箱」を用意し、対局を箱から始められる

## Description

定義に box がなければ、id box（名前：箱、卓の外、全員に見える）を足す。初期の置き場のない部品は箱に入る。「箱から始める」で作った対局は、すべての部品が箱にあり、状態は定義の既定の値。基本の操作 gather（あるエリアの部品を、種類を絞って、向きを決めてまとめて動かす）と、アクションの手順の each: players（プレイヤーごとに繰り返す）で、準備の手順を書ける。準備の後の局面を、定義の初期の置き場と比べられる。

## Acceptance Criteria

- **AC-043-1**
  - **Given** box を書いていない定義
  - **When** 開発者がライブラリで定義を読み込む
  - **Then** エリア box がある
- **AC-043-2**
  - **Given** かがり火の定義
  - **When** エージェントが「箱から始める」で対局を作る
  - **Then** 24 枚のカードがすべて箱にあり、山札は空
- **AC-043-3**
  - **Given** AC-043-2 の対局
  - **When** P1 が準備のアクション setup を行う
  - **Then** 山札は 18 枚、各プレイヤーの手札は 3 枚、手番は P1
- **AC-043-4**
  - **Given** AC-043-3 の局面
  - **When** エージェントが定義の初期の置き場と比べる
  - **Then** 違いとして、手札に配った 6 枚と、山札の 18 枚の向きと順番が示される
