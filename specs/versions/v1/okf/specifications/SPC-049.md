# SPC-049：画面は、卓に出す情報を見る人が選べるようにし、既定では名前だけを出す

## Description

卓に出す情報を「表示」の切り替えで選ぶ：部品の ID、状態、公開範囲、縦横の印、エリアの ID と持ち主、見えない理由、操作の説明。既定はどれも出さず、カードは名前、エリアは名前だけ。カードの形（縦長・横長・裏面）は常に出す。選んだ部品は卓の上でも状態を出し、詳しい情報は調べる欄に出す。選んだ表示は見る人のブラウザにだけ残す（RUL-003 #4）。

## Acceptance Criteria

- **AC-049-1**
  - **Given** 画面を初めて開いた（表示の切り替えを触っていない）
  - **When** ゲーム設計者が卓を見る
  - **Then** カードには名前だけが出て、ID・状態・公開範囲の文字は出ない
- **AC-049-2**
  - **Given** AC-049-1 の画面
  - **When** ゲーム設計者が表示の「状態」を入れる
  - **Then** カードに状態が出て、画面を開き直しても入れたまま
- **AC-049-3**
  - **Given** AC-049-1 の画面
  - **When** ゲーム設計者がカードを選ぶ
  - **Then** そのカードだけ卓の上で状態が出て、調べる欄に ID・状態・公開範囲が出る
