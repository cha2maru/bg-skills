# SPC-055：ライブラリは、エージェントが手間なく進められるように、自動の進行・結果の進行・引数の自動選択・場所の性質・費用の確認を持つ

## Description

カタンの 2 回目の対局（notes/impl-4/catan-review.md）の指摘への対応。フェイズの auto（メインアクションを max 回行い終えたら次へ自動で進む。記録に auto の印つきの advance を残す）。act・op の結果に、移った後の進行（段階・手番・フェーズ・行えるアクション）を添える。引数の pick: first（省いたら条件を満たす最初の候補。区別しないコマ）。種類の fixture: true（港などの場所の性質。空き・上限の判定に数えない）。アクション全体の require（費用など）を、候補の結果（action_problems）にも出す。区別しない部品の操作も、移る元・先の表面が見えない人には記録で種類を伏せる。最長の路は、入ってきた端とは別の端から先へ進む（分かれ道で折り返さない）。

## Acceptance Criteria

- **AC-055-1**
  - **Given** 初期配置の手番（max 2、auto）
  - **When** P1 が開拓地と街道を 1 つずつ置く
  - **Then** 手番は自動で P2 に移る
- **AC-055-2**
  - **Given** P1 の手元に開拓地が 3 つ
  - **When** P1 が開拓地の引数を省いて「初期配置で開拓地を置く」を行う
  - **Then** 手元の最初の開拓地が置かれる
- **AC-055-3**
  - **Given** 港のある辺
  - **When** エージェントがその辺の空きを確かめる
  - **Then** 空いている（港は数えない）
- **AC-055-4**
  - **Given** 1 つの交点に 3 本の街道が集まる（Y 字）
  - **When** エージェントが最長の街道の指標を求める
  - **Then** 2
- **AC-055-5**
  - **Given** P2 が P1 の手札からランダムに 1 枚取った記録
  - **When** P3 の見え方で記録を求める
  - **Then** 取った資源の種類は伏せられ、P1 の見え方では示される
