# SPC-027：画面は、定義のエリアを入れ子のまま描き、卓の配置があれば見る立場のプレイヤーを手前にして描く

## Description

入れ子の子エリアは親の中に描く。位置（pos）を持つ子は格子に並べる。卓の配置がない定義は、エリアを上から順に並べる。

## Acceptance Criteria

- **AC-027-1**
  - **Given** 卓の配置（中央：山札・捨て札、席：プレイヤーエリア）を持つ 2 人のゲーム
  - **When** ゲーム設計者が見る立場を P2 にする
  - **Then** P2 のプレイヤーエリアが手前（下）に、P1 のプレイヤーエリアが対面（上）に、山札と捨て札が中央に描かれる
- **AC-027-2**
  - **Given** プレイヤーエリアの中に火と手札がある定義
  - **When** ゲーム設計者が画面を開く
  - **Then** 火と手札が、プレイヤーエリアの枠の中に描かれる
