# SPC-011：ライブラリは、局面を 1 人のプレイヤーから見た見え方に切り出し、見えない情報をその理由とともに示す

## Description

見えるかどうかは、オブジェクトの状態（表・裏）、エリアの公開範囲（情報の段階ごと）、既知（置いた本人・のぞき見た人が知っていること）から決める（判断の記録 G4・G24）。既知は一度記録したら消さない。切り直しで中身との対応が消える場合は外す（判断の記録 G24）。

## Acceptance Criteria

- **AC-011-1**
  - **Given** P1 の手札に 3 枚あり、手札の公開範囲が「枚数は全員、表面は持ち主」の局面
  - **When** キーパーが P2 の見え方を求める
  - **Then** P1 の手札は枚数 3 だけが示され、表面は「持ち主だけに見える」と理由つきで示される
- **AC-011-2**
  - **Given** AC-011-1 と同じ局面
  - **When** キーパーが P1 の見え方を求める
  - **Then** P1 の手札の 3 枚の表面が示される
- **AC-011-3**
  - **Given** 山札に 12 枚あり、山札の公開範囲が「枚数は全員、表面と順番は誰にも見せない」の局面
  - **When** キーパーが P1 の見え方を求める
  - **Then** 山札は枚数 12 だけが示され、表面と順番は「誰にも見えない」と示される
- **AC-011-4**
  - **Given** 脚本家が医者に裏向きで札を置き、既知に「脚本家が知っている」がある局面
  - **When** キーパーが脚本家の見え方を求める
  - **Then** 医者の上の札の中身が示される
- **AC-011-5**
  - **Given** AC-011-4 と同じ局面
  - **When** キーパーが主人公 A の見え方を求める
  - **Then** 医者の上に札が 1 枚あることだけが示され、中身は見えないと示される
