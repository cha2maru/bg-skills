# SPC-037：スクリプトは、六角のマス目を TTS の卓に六角の並びで書き出す

## Description

マスの目印は、六角の並びの位置に置く（タイルの形は四角のまま）。【要確認：仮定＝六角のタイル（Custom_Tile の形の番号）は実機で確かめてから】

## Acceptance Criteria

- **AC-037-1**
  - **Given** 半径 2 の六角のマス目の盤
  - **When** エージェントが bg tts で書き出す
  - **Then** 19 個のマスの目印の位置が、隣り合うマスの中心の距離がどれも等しい六角の並びになる
