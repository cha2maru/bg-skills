# SPC-069：ライブラリは、終わりの条件から勝ち・負け・引き分けと時機を決め、終わりの得点計算・同点の比べ方・手番の終わりの手順を扱う

## Description

RUL-015 への対応（検討は notes/endgame/gates.md）。flow.end_when の各件に、結果の決め方（winners: 式・losers: 式・winners: scoring・draw: true。式の値は value）と時機（timing：now・turn_end・round_end）を書ける。並びが優先の順。flow.auto_end: true なら、条件を満たして時機が来た操作のあとに、結果（席ごとの win・lose・draw と文、得点の順位）を書いた end の操作を記録する（アクションと一緒に undo で戻る）。flow.scoring（by：得点の指標、tiebreak：同点のときに比べる指標の並び、low：少ないほうが上）から順位を作り、なお同じなら同じ順位。見え方に standings（見えない得点があればプレイヤーには出さない）と、キーパーには end_preview（今満たしている終わりの条件と結果）。手番・段階の on_end は、手番が替わる前（手番の人は前の人のまま）に手順を行う。手順の end は draw: true で引き分け。bg complexity でルールの複雑さの目安を出す。

## Acceptance Criteria

- **AC-069-1**
  - **Given** 3 人で「誰かが 10 点に届いたら、その巡を終えて得点の多い人の勝ち」
  - **When** P1 が巡の途中で 10 点に届き、P2 も届き、P3 が手番を終える
  - **Then** P1 の時点では終わらず（キーパーには予告）、巡の終わりで終わる。P1・P2 が同点（お金も同じ）なら 2 人の勝ち
- **AC-069-2**
  - **Given** 全員 9 点で、P2 だけお金が 2
  - **When** 全員が 1 点ずつ取って巡を終える
  - **Then** 同点をお金で比べ、P2 だけが勝ち
- **AC-069-3**
  - **Given** 手番の終わりに手札を 3 枚までにする（on_end）
  - **When** 手札 4 枚で手番を終える
  - **Then** 1 枚を捨て札にして 3 枚になる
- **AC-069-4**
  - **Given** ルーン決闘（auto_end、losers: value）
  - **When** どちらかが 10 ダメージを受ける
  - **Then** エンジンが結果（相手の勝ち）を記録して終わる
