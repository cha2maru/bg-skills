# SPC-023：スキルは、利用者が頼むと、集計とゲーム定義の数値から、バランスの偏りの指摘と直す案を報告する

## Description

偏りの観点：勝率の偏り（先手・後手、席ごと）、対局の長さ、使われない部品・ルール（判断の記録 G19）。直す案は定義の変更の案で、定義には書かない（書くのは利用者の了承の後。REQ-002 の版で残す）。

## Acceptance Criteria

- **AC-023-1**
  - **Given** 先手が 10 局中 8 勝している集計
  - **When** ゲーム設計者がエージェントにバランスの検討を頼む
  - **Then** 報告に先手の勝率の偏りの指摘と、ゲーム定義の要素を名指しした直す案がある
- **AC-023-2**
  - **Given** AC-023-1 の報告
  - **When** ゲーム設計者が報告を読んだ後
  - **Then** ゲーム定義は変わっていない
