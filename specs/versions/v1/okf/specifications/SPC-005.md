# SPC-005：ライブラリは、種類ごとに状態の項目と値ごとの意味の文、属性の項目、使い方を保持する

## Description

オブジェクトは状態を持ち、それぞれの状態に意味を付けてよい（RUL-001 #18）。変更されない状態（カードのテキストなど）は属性として持つ（#19）。置き方・使い方で働きが変わるもの（#20）は、使い方ごとに「いつ」と働きを自然文で書く（判断の記録 G13）。

## Acceptance Criteria

- **AC-005-1**
  - **Given** カードの種類が状態「向き」（値：表・裏）と、値ごとの意味の文を持つゲーム定義
  - **When** エージェントがライブラリで状態「向き」の値「裏」の意味を求める
  - **Then** 値「裏」の意味の文が示される
- **AC-005-2**
  - **Given** 風カードの種類が使い方を 2 つ（手札から使う／薪の下に差し込まれている間）持つゲーム定義
  - **When** エージェントがライブラリで風カードの使い方を求める
  - **Then** 2 つの使い方が、それぞれの「いつ」と働きの文、参照するルールとともに示される
