# SPC-013：スキルは、決まったチェックリストの項目ごとに、ゲーム定義に記述があるかを報告する

## Description

チェックリストの項目：人数、準備、手番の進み方、終了の条件、同点の扱い、山札が尽きたときの扱い、手札の上限。項目は理解テストの質問の元にも使う（判断の記録 G10）。チェックリストの項目は上の 7 つから始める（推奨で決めた。RUL-018）

## Acceptance Criteria

- **AC-013-1**
  - **Given** 同点の扱いが書かれていないゲーム定義
  - **When** 利用者がエージェントにチェックリストの確認を頼む
  - **Then** 報告で「同点の扱い」が記述なしとして示される
- **AC-013-2**
  - **Given** チェックリストの全項目が書かれたゲーム定義
  - **When** 利用者がエージェントにチェックリストの確認を頼む
  - **Then** 報告で全項目が記述ありとして示される
