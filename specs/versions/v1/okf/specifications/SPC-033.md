# SPC-033：スクリプトは、局面を TTS の Saved Object（JSON）と、サムネイル・無地の表裏の画像に書き出す

## Description

順番を持つエリアの 2 枚以上は Deck（先頭が山の上）、手札は持ち主の色の手札ゾーン、表裏は回転 Z、横向きは回転 Y 90。カードの区別は名前・説明と、GMNotes の bg-skills の ID。卓の配置があればそれに従って置く。GUID は ID から決まる。

## Acceptance Criteria

- **AC-033-1**
  - **Given** 山札 22 枚、P1 の火に表向き・横向きの薪がある局面
  - **When** エージェントが bg tts で書き出す
  - **Then** JSON に 22 枚の Deck（先頭が山の一番上）があり、薪は回転 Z 0・回転 Y 90 で置かれる
- **AC-033-2**
  - **Given** 2 人のゲームの局面
  - **When** エージェントが bg tts で書き出す
  - **Then** 持ち主の色の手札ゾーンが 2 つあり、GUID が重複しない
- **AC-033-3**
  - **Given** AC-033-1 の書き出し
  - **When** ゲーム設計者が出力先を見る
  - **Then** JSON と同じ名前のサムネイル PNG と、表・裏の PNG がある
