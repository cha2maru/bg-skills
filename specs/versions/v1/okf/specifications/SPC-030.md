# SPC-030：画面は、見えない部品を、見えない理由とともに裏面で描く

## Description

枚数だけ分かるエリアは裏面を枚数分（20 枚まで）並べ、順番を持つ置き場は山の形で枚数を添える。手札のように見せる相手を絞ったエリアでは、向きを出さず、誰に見えるかを出す（RUL-002 #7・#9）。

## Acceptance Criteria

- **AC-030-1**
  - **Given** P2 の手札が 3 枚の局面
  - **When** ゲーム設計者が見る立場を P1 にする
  - **Then** P2 の手札に裏面が 3 枚描かれる
- **AC-030-2**
  - **Given** 山札が 18 枚の局面
  - **When** ゲーム設計者が見る立場を P1 にする
  - **Then** 山札が山の形で「18 枚」と描かれる
- **AC-030-3**
  - **Given** P1 の手札のカード
  - **When** ゲーム設計者が見る立場を P1 にする
  - **Then** カードは表で描かれ、「持ち主（P1）だけに見える」と示され、向き（facing）は示されない
